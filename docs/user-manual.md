## 1. ระบบนี้ใช้ทำอะไร

Haris Payroll ใช้จัดการข้อมูลพนักงานของร้านอาหารที่มีหลายสาขา ตั้งแต่พนักงานเริ่มงาน บันทึกวันทำงาน ขอลา ทำ OT บันทึกเงินที่เบิกหรือค้างชำระ ไปจนถึงคำนวณเงินเดือน ออกสลิป และเตรียมไฟล์ส่งออก

ข้อมูลแต่ละส่วนเกี่ยวข้องกัน เช่น บันทึกว่าพนักงานมาสายและต้องหักเงิน จะมีผลต่อเงินเดือน หรือ OT ที่ยังไม่อนุมัติจะยังไม่กลายเป็นรายได้ที่จ่ายให้พนักงาน

ลำดับงานหลักคือ:

**เตรียมองค์กรและบัญชี → เพิ่มพนักงาน → บันทึกวันทำงาน/คำขอ → พิจารณาคำขอ → ตรวจเงินและหนี้ → คำนวณตัวอย่าง → ล็อกรอบ → ออกสลิป/ส่งออกไฟล์**

คำที่ต้องรู้:

| คำ | ความหมายสำหรับผู้ใช้งาน |
|---|---|
| ร้าน | องค์กรหลักที่มีสาขาอยู่ใต้ร้านนั้น |
| สาขา | สถานที่ทำงานแต่ละแห่งของร้าน |
| แผนก | กลุ่มงานภายในสาขา เช่น ครัวหรือบริการ |
| ตำแหน่ง | หน้าที่ของพนักงาน เช่น พนักงานเสิร์ฟ |
| บัญชีผู้ใช้ | ชื่อผู้ใช้และสิทธิ์สำหรับเข้าสู่เว็บ |
| แฟ้มพนักงาน | ข้อมูลบุคคลและการทำงาน บัญชีผู้ใช้ต้องเชื่อมแฟ้มนี้จึงทำรายการส่วนตัวได้ |
| ประวัติการจ้าง | สาขา แผนก ตำแหน่ง เงินเดือน และสวัสดิการที่มีผลในแต่ละช่วงเวลา |
| OT | งานล่วงเวลาที่ต้องได้รับอนุมัติก่อนนำไปจ่าย |
| รอบเงินเดือน | ช่วงวันที่ที่นำมาคำนวณเงินเดือน ปัจจุบันหน้าเว็บเปิดเป็นรายเดือน |
| คำนวณตัวอย่าง / Preview | ตรวจผลก่อนยืนยันรอบ ยังแก้ข้อมูลต้นทางและคำนวณใหม่ได้ |
| ล็อกรอบ | ยืนยันผลและตรึงข้อมูลที่ใช้คำนวณเป็นประวัติ |
| Adjustment | รายการเพิ่มรายได้หรือเพิ่มรายการหักเพื่อแก้ส่วนต่างจากรอบที่ล็อกแล้ว |
| Audit | ประวัติว่าใครทำอะไร กับข้อมูลใด และเมื่อไร |

## 2. เตรียมตัวก่อนใช้และรู้จักสิทธิ์

### 2.1 สิ่งที่ต้องขอจากผู้ดูแล

ก่อนเริ่มใช้ ขอ **ที่อยู่เว็บ**, **ชื่อผู้ใช้**, **รหัสผ่านเริ่มต้น**, **บทบาท**, และ **สาขา/แผนกที่รับผิดชอบ** จาก HR หรือเจ้าของระบบ หากเป็นพนักงาน ให้ผู้ดูแลยืนยันว่าบัญชีเชื่อมแฟ้มพนักงานถูกคนแล้ว

ใช้ที่อยู่เว็บที่องค์กรให้มา ไม่จำเป็นต้องติดตั้ง Bun, Docker หรือฐานข้อมูล ผู้ที่เปิดระบบพัฒนาในเครื่องตาม README ใช้ `http://localhost` ได้เมื่อระบบทำงานอยู่ แต่ที่อยู่นี้ไม่ใช่ที่อยู่เว็บขององค์กรทุกแห่ง

## 3. เข้าสู่ระบบ เปลี่ยนรหัสผ่าน และออกจากระบบ

### 3.1 เข้าสู่ระบบ

1. เปิดที่อยู่เว็บในเบราว์เซอร์ ระบบมีหน้าเข้าสู่ระบบที่ `/login`
2. กรอก **ชื่อผู้ใช้** ที่ได้รับ เช่น `somchai.employee` ไม่ใช่ชื่อจริงของพนักงาน เว้นแต่ผู้ดูแลตั้งไว้แบบนั้น
3. กรอก **รหัสผ่าน** หากต้องตรวจตัวอักษร กด **แสดง** แล้วกด **ซ่อน** เมื่อเสร็จ
4. กด **เข้าสู่พื้นที่ทำงาน** เพียงครั้งเดียว
5. รอจนระบบเปิดหน้าหลักของบัญชี

หน้าแรกตามบทบาท: Employee ไป **การลา**, Supervisor/Branch Manager ไป **ลงเวลา**, HR ไป **เงินเดือน**, Owner ไป **การตั้งค่า** บัญชีที่มีหลายบทบาทเริ่มตามลำดับ Owner → HR → Branch Manager → Supervisor → Employee

ถ้าระบบแจ้งชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง ให้ตรวจการพิมพ์และภาษาแป้นพิมพ์ ถ้าแจ้งว่าบัญชีถูกพักชั่วคราว ให้รอหรือติดต่อผู้ดูแล ไม่ลองรหัสจำนวนมากต่อเนื่อง

### 3.2 เปลี่ยนรหัสผ่านของตนเอง

ทำได้ทุกบทบาท และควรทำเมื่อได้รับรหัสผ่านชั่วคราว:

1. กดเมนู **การตั้งค่า**
2. ไปส่วน **รหัสผ่านของฉัน**
3. กรอก **รหัสผ่านปัจจุบัน**
4. กรอก **รหัสผ่านใหม่** อย่างน้อย 8 ตัวอักษร และไม่ซ้ำรหัสเดิม
5. กรอก **ยืนยันรหัสผ่านใหม่** ให้ตรงกัน
6. กด **เปลี่ยนรหัสผ่าน**
7. ตรวจข้อความ **เปลี่ยนรหัสผ่านเรียบร้อยแล้ว ใช้รหัสผ่านใหม่ในการเข้าสู่ระบบครั้งถัดไป**

ถ้าลืมรหัสปัจจุบัน ให้ HR/Owner รีเซ็ตผ่านหน้าบัญชีผู้ใช้ หน้า login ยังไม่มีปุ่มลืมรหัสผ่านสำหรับกู้คืนด้วยตนเอง

### 3.3 เมนูและการออกจากระบบ

คอมพิวเตอร์มีเมนูด้านซ้าย แบ่งเป็นงานประจำวัน บุคลากร การเงิน และระบบ ชื่อบัญชีแสดงที่ส่วนหัว หน้า **ภาพรวม** เป็นทางลัดเริ่มงาน ไม่ใช่กราฟสรุปยอดเงินเดือนทั้งองค์กร

บนหน้าจอแคบหรือโทรศัพท์ กด **เมนูหลัก** ด้านบนเพื่อแสดงรายการเมนู ตารางกว้างบางหน้าต้องเลื่อนแนวนอน

บนคอมพิวเตอร์ กด **ออกจากระบบ** ใต้ชื่อบัญชีด้านล่างของแถบซ้าย แล้วตรวจว่ากลับหน้า login แล้ว การปิดแท็บอย่างเดียวไม่เท่ากับออกจากระบบ

**ข้อจำกัดบนโทรศัพท์:** โค้ดปัจจุบันวางปุ่มออกจากระบบเฉพาะแถบซ้ายที่ถูกซ่อนบนจอแคบ หากไม่พบปุ่ม ให้ใช้หน้าจอกว้างที่แสดงแถบซ้ายเพื่อออกจากระบบ หรือให้ผู้ดูแลช่วยดำเนินการ ไม่ถือว่าปิดแท็บแล้ว session สิ้นสุด

## 4. อ่านหน้าจอและกรอกข้อมูลให้ถูก

### 4.1 เลือกพนักงานให้สำเร็จก่อนทำรายการ

หลายหน้าใช้ช่อง **ค้นหาชื่อหรือรหัสพนักงาน**:

1. คลิกช่องแล้วพิมพ์ชื่อหรือรหัส
2. รอรายการแนะนำ
3. เลือกรายการที่ตรงคน เช่น `EMP001 · สมชาย ใจดี`
4. ตรวจว่าข้อความใต้ช่องเปลี่ยนเป็น **เลือกพนักงานแล้ว**
5. กดปุ่มโหลดข้อมูลของหน้านั้น

พิมพ์ชื่ออย่างเดียวแล้วไม่เลือกรายการ อาจยังไม่มีพนักงานที่ถูกเลือกจริง ก่อนส่งคำขอหรือบันทึก ให้ตรวจคนด้านบนอีกครั้ง โดยเฉพาะเมื่อเปลี่ยนพนักงานระหว่างทำงาน

Employee ในหน้า Leave/OT จะเห็นชื่อของตนเองแทนช่องค้นหา ถ้าเห็น **บัญชียังไม่เชื่อมข้อมูลพนักงาน** ให้ผู้ดูแลแก้การเชื่อมบัญชีก่อน

### 4.2 วันที่ เงิน และ ID

| ข้อมูล | วิธีกรอก |
|---|---|
| วันที่ | เลือกจากปฏิทิน ตรวจปีและเดือนให้ถูก ระบบเก็บวันที่เป็น ค.ศ. เช่น `2026-10-12` คือ 12 ต.ค. 2569 |
| วันและเวลา | กรอกทั้งวันที่และเวลา ใช้เครื่องที่ตั้งเขตเวลาให้ตรงกับงาน เช่น Asia/Bangkok |
| เงิน | กรอกตัวเลขไม่ใส่ `฿` หรือเครื่องหมายคั่นหลักพัน เช่น `18000.00` |
| เงินเดือน/สวัสดิการตอนเพิ่มพนักงาน | ต้องมีทศนิยม 2 ตำแหน่ง เช่น `18000.00` และ `0.00` |
| นาทีสาย | กรอกจำนวนนาที เช่น `15` ไม่ใช่ `0.15` ชั่วโมง |
| ชั่วโมง OT | เช่น 2 ชั่วโมง 30 นาที กรอก `2.50` ไม่ใช่ `2.30` |
| ID | หมายเลขภายในระบบ ต้องใช้ชนิดที่ตรงกับช่อง ไม่ใช่ชื่อหรือรหัสที่องค์กรตั้ง |

**รหัสพนักงาน เช่น `EMP001` กับ Employee ID เช่น `17` เป็นคนละค่า** หน้าสร้างและเชื่อมบัญชีใช้ตัวเลือกค้นหาชื่อ/รหัสพนักงาน เลือกรายการที่ตรงคนแล้วระบบส่ง ID ให้เอง

Payroll Period ID คือรหัสรอบทั้งเดือน, Payroll Record ID คือรหัสผลเงินเดือนของพนักงานหนึ่งคนในรอบนั้น, Payslip ID คือรหัสสลิป ห้ามนำทั้งสามมาใช้แทนกัน

หน้าเงินเดือน รายการปรับปรุง และสลิปใช้ตัวเลือกตามร้าน งวด และพนักงาน ให้เลือกรายการจากชื่อที่แสดง ไม่เดาตัวเลข ID

### 4.3 สถานะและการยืนยันผล

| สถานะ | ต้องเข้าใจอย่างไร |
|---|---|
| รอพิจารณา | ส่งคำขอแล้ว แต่ยังไม่ได้อนุมัติ |
| อนุมัติแล้ว | ผ่านการตัดสินตามสิทธิ์แล้ว |
| ไม่อนุมัติ | คำขอถูกปฏิเสธ ดูเหตุผลถ้ามี |
| ฉบับร่าง | รอบเงินเดือนยังไม่ล็อก |
| คำนวณแล้ว | มีการคำนวณตัวอย่าง ยังไม่ใช่การยืนยันจ่าย |
| ล็อกแล้ว | ผลเงินเดือนถูกตรึง ห้ามแก้ทับย้อนหลัง |
| สลิปออกแล้ว / generated | สร้างสลิปแล้ว ไม่ได้แปลว่าเงินเข้าบัญชีแล้ว |
| ยกเลิกสลิป / voided | สลิปถูกยกเลิก แต่ยังเก็บประวัติ |

หลังทำรายการ ให้ตรวจข้อความสำเร็จและโหลดรายการดูอีกครั้ง ปุ่มที่กดไม่ได้อาจเกิดจากกำลังบันทึก ยังเลือกข้อมูลไม่ครบ ไม่มีสิทธิ์ หรือสถานะไม่อนุญาต

บางหน้าขึ้น “ไม่พบรายการ” ก่อนกดโหลด อย่าเพิ่งสรุปว่าข้อมูลหาย ให้เลือกข้อมูลและกดโหลดก่อน

## 5. ดูทะเบียนและแฟ้มพนักงาน

**ผู้ใช้:** ทุกบทบาท แต่เห็นข้อมูลตามสิทธิ์

1. กดเมนู **พนักงาน** เพื่อเปิด **ทะเบียนพนักงาน**
2. พิมพ์ใน **ค้นหาชื่อหรือรหัสพนักงาน**
3. เลือก **สถานะ** ถ้าต้องการ เช่น ทำงานอยู่ หรือสิ้นสุดการจ้าง
4. กด **ค้นหา** ใช้ **หน้าก่อน / หน้าถัดไป** เมื่อมีหลายหน้า
5. กดชื่อพนักงานเพื่อเปิดแฟ้ม
6. เลือกแท็บที่ต้องการ

| แท็บ | ใช้ดูอะไร |
|---|---|
| ข้อมูลทั่วไป | ข้อมูลบุคคล การทำงานปัจจุบัน และข้อมูลติดต่อที่สิทธิ์อนุญาต |
| ประวัติการจ้าง | ช่วงสังกัด ตำแหน่ง ประเภทจ้าง เงินเดือน/สวัสดิการตามสิทธิ์ |
| บัญชีธนาคาร | บัญชีรับเงินและบัญชีหลัก เลขบัญชีแสดงแบบปกปิด |
| วันหยุด | วันหยุดประจำสัปดาห์และช่วงวันที่มีผล |
| เอกสาร | แนบ/ดาวน์โหลด PDF/PNG/JPEG ไม่เกิน 5 MB ตามสิทธิ์ |

ถ้าข้อมูลไม่ได้แสดง อาจเป็นเพราะไม่มีข้อมูลหรือไม่มีสิทธิ์เห็น ไม่ควรตีความว่าเงินเดือนเป็นศูนย์เพียงเพราะไม่เห็นตัวเลข Employee ดูของตนเอง หัวหน้าแผนกและผู้จัดการสาขาดูในขอบเขต โดยข้อมูลอ่อนไหวอาจถูกซ่อน

กด **โหลดใหม่** เพื่อเรียกข้อมูลอีกครั้ง HR/Owner แก้ชื่อและข้อมูลติดต่อผ่านส่วนแก้ข้อมูลพนักงานได้ การเปลี่ยนสถานะต้องมีเหตุผล การสิ้นสุดการจ้างต้องระบุวันทำงานสุดท้ายและยืนยัน ระบบปิดช่วงประวัติการจ้างโดยไม่ลบข้อมูลเดิม และปฏิเสธการเปลี่ยนข้อมูลที่กระทบงวดล็อกแล้ว

## 6. เพิ่มพนักงานและดูแลประวัติการจ้าง

**ผู้ใช้:** HR และ Owner

### 6.1 เตรียมก่อนเพิ่ม

ต้องมีร้าน สาขา แผนก และตำแหน่งให้เลือกก่อน เตรียมรหัสพนักงาน วันที่เริ่มงาน ชื่อ นามสกุล เลขบัตรประชาชนหรือหนังสือเดินทาง เงินเดือนฐาน สวัสดิการ และข้อมูลธนาคาร/วันหยุดถ้ามี

### 6.2 เพิ่มพนักงานใหม่

1. เปิด **พนักงาน** แล้วกด **เพิ่มพนักงาน**
2. ขั้น **1 · ข้อมูลพนักงาน**: กรอกรหัสพนักงาน วันที่เริ่มงาน ชื่อ และนามสกุล
3. กรอกเลขบัตรประชาชนหรือเลขหนังสือเดินทางอย่างน้อยหนึ่งรายการ เป็นการกรอกเลข ไม่ใช่อัปโหลดรูปเอกสาร
4. กด **ถัดไป**
5. ขั้น **2 · การจ้างและตัวเลือก**: เลือก **ร้าน → สาขา → แผนก** และ **ตำแหน่ง**
6. เลือกประเภทจ้าง เต็มเวลา พาร์ตไทม์ หรือชั่วคราว
7. กรอกเงินเดือนฐาน เช่น `18000.00` และสวัสดิการ เช่น `1000.00` หากไม่มีให้กรอก `0.00`
8. ติ๊กวันหยุดประจำสัปดาห์ตามที่ตกลงกับพนักงาน
9. ถ้าต้องการเพิ่มบัญชีรับเงิน ติ๊ก **เพิ่มบัญชีธนาคาร** แล้วกรอกรหัสธนาคาร ชื่อธนาคาร ชื่อเจ้าของบัญชี และเลขบัญชี บัญชีแรกนี้ถูกตั้งเป็นบัญชีหลัก
10. ถ้าต้องการให้พนักงานเข้าเว็บ ติ๊ก **สร้างบัญชีเข้าใช้งาน** แล้วกรอกชื่อผู้ใช้ ตัวอักษรอังกฤษ ตัวเลข จุด ขีดกลาง หรือขีดล่าง ความยาว 3–100 ตัวอักษร
11. ตรวจทุกส่วน แล้วกด **สร้างพนักงาน**
12. ตรวจหน้าสร้างสำเร็จ ถ้ามีรหัสผ่านชั่วคราว ให้จัดเก็บและส่งให้เจ้าของบัญชีผ่านช่องทางภายในที่ปลอดภัยทันที แล้วตรวจบทบาทในเมนูบัญชีผู้ใช้

ข้อมูลชุดนี้ส่งพร้อมกัน หากระบบแจ้งล้มเหลว ให้ตรวจรายการก่อนกดซ้ำ โดยเฉพาะเมื่อเครือข่ายขาดหลังส่งคำขอแล้ว ช่องเลขบัญชีเต็มถูกล้างหลังส่งคำขอ และเมื่อย้อนกลับขั้นแรก จึงอาจต้องกรอกใหม่ก่อนส่งอีกครั้ง

### 6.3 ย้ายสาขา เปลี่ยนตำแหน่ง หรือปรับเงินเดือน

1. เปิดแฟ้มพนักงาน → **ประวัติการจ้าง**
2. ไปส่วน **จัดการข้อมูล → เพิ่มช่วงการจ้างใหม่**
3. เลือกร้าน สาขา แผนก ตำแหน่ง ประเภทการจ้าง และกรอกเงินเดือน/สวัสดิการของช่วงใหม่ให้ครบ แม้เปลี่ยนแค่เงินเดือน
4. เลือก **มีผลตั้งแต่** ให้เป็นวันที่เริ่มใช้ข้อมูลใหม่
5. ระบุวันสิ้นสุดเฉพาะถ้ามีกำหนดแน่นอน
6. บันทึกและตรวจว่ามีแถวใหม่ พร้อมประวัติเก่าอยู่ครบ

ตัวอย่าง: ปรับเงินเดือนวันที่ 1 พ.ย. 2026 ให้เพิ่มช่วงใหม่ที่เริ่ม `2026-11-01` ถ้าช่วงเดิมยังไม่มีวันสิ้นสุด ระบบจะปิดช่วงเดิมที่วันก่อนหน้า ห้ามแก้ข้อมูลเดิมย้อนหลังเพื่อทำให้ดูเหมือนพนักงานเคยได้รับเงินเดือนใหม่มาตลอด

### 6.4 จัดการบัญชีรับเงิน

เปิดแฟ้ม → **บัญชีธนาคาร** แล้วใช้แบบฟอร์มตามงาน:

- **เพิ่มบัญชีธนาคาร:** กรอกรหัส/ชื่อธนาคาร ชื่อบัญชี เลขบัญชีเต็ม และเลือกว่าจะเป็นบัญชีหลักหรือไม่
- **แก้ข้อมูลบัญชี:** เลือกบัญชีแล้วแก้ช่องที่ต้องการ เลขบัญชีใหม่เว้นว่างได้เมื่อไม่ได้เปลี่ยนเลข
- **ตั้งเป็นบัญชีหลัก:** เลือกบัญชีที่ใช้งานอยู่และตั้งเป็นบัญชีรับเงินหลัก
- **ปิดใช้งานบัญชี:** เลือกบัญชีที่จะปิด หากเป็นบัญชีหลัก ให้เลือกบัญชีหลักทดแทนตามข้อกำหนดของระบบ

ตรวจเลขบัญชีจากหลักฐานก่อนบันทึก เลขที่ถูกปกปิดบนหน้าเว็บไม่ใช่เลขที่นำไปกรอกแทนเลขเต็มได้ และก่อนส่งออกไฟล์จ่ายเงินให้ตรวจบัญชีหลักอีกครั้ง

### 6.5 จัดการวันหยุดประจำสัปดาห์

1. เปิดแฟ้ม → **วันหยุด**
2. ส่วน **เพิ่มช่วงวันหยุด**: เลือกวัน เช่น วันจันทร์ เลือกวันเริ่มมีผล และวันสิ้นสุดถ้ามี แล้วบันทึก
3. ถ้าจะสิ้นสุดวันหยุดเดิม ใช้ **สิ้นสุดช่วงวันหยุด** เลือกช่วงที่ใช้อยู่และกรอกวันสิ้นสุด
4. ก่อนเพิ่มช่วงใหม่ ตรวจช่วงเดิมเพื่อไม่ให้ซ้อนกัน

นี่คือวันหยุดประจำสัปดาห์ของพนักงาน ไม่ใช่การอนุมัติคำขอลาหรือการตั้งวันหยุดนักขัตฤกษ์

## 7. บันทึกและแก้ไขวันทำงาน

**ผู้ใช้:** Supervisor, Branch Manager, HR, Owner ในขอบเขตสิทธิ์ หน้านี้เป็นการบันทึกโดยผู้รับผิดชอบ ไม่ใช่ปุ่มให้ Employee ตอกบัตรด้วยตนเอง

### 7.1 ดูรายการก่อนบันทึก

1. เปิด **ลงเวลา**
2. เลือกพนักงานให้สำเร็จ
3. เลือก **ตั้งแต่** และ **ถึง**
4. กด **โหลดรายการ**
5. ตรวจวันทำงาน สาขา สถานะ เวลาเข้า/ออก นาทีสาย หักเงิน และแหล่งที่มา

### 7.2 เพิ่มวันทำงาน

1. ใช้พนักงานที่เลือกด้านบน
2. ไปส่วน **บันทึกวันทำงาน**
3. กรอก **รหัสสาขา** เป็น Branch ID ภายในระบบ ถ้าไม่ทราบขอจากผู้ดูแล
4. เลือก **วันที่ทำงาน**
5. เลือกสถานะ: มาทำงาน มาสาย ขาดงาน วันหยุดประจำสัปดาห์ หรือวันหยุดนักขัตฤกษ์
6. กรอกเวลาเข้าและออกเป็นวัน/เวลาจริงเมื่อเกี่ยวข้อง
7. กรอก **นาทีที่มาสาย** ถ้าไม่สายให้เป็น `0`
8. ติ๊ก **หักเงิน** ตามสถานะและนโยบายที่ได้รับอนุมัติ ช่องนี้มีผลต่อเงินเดือน อย่าสันนิษฐานว่าเลือก “มาสาย” แล้วช่องหักเงินจะถูกเลือกอัตโนมัติ
9. กรอกหมายเหตุ แล้วกด **บันทึกวันทำงาน**
10. ตรวจข้อความ **บันทึกวันทำงานแล้ว** และดูรายการในช่วงวันที่ที่ครอบคลุมวันนั้น

หนึ่งคนมีรายการได้หนึ่งรายการต่อวัน หากมีรายการเดิมแล้วให้แก้รายการเดิม สาขาในวันทำงานเป็นข้อมูลของวันนั้น ไม่ใช่สาขาปัจจุบันที่เปลี่ยนย้อนหลังเมื่อพนักงานย้าย

### 7.3 แก้รายการเดิม

1. โหลดรายการตามบท 7.1
2. ส่วน **แก้ไขรายการ** เลือกวันทำงานจากรายการที่โหลดมา
3. ตั้งสถานะ นาทีสาย และช่องหักเงินให้ถูกทั้งหมด อย่าคิดว่าค่าเริ่มต้นในฟอร์มถูกเติมจากรายการเดิมทุกช่อง
4. กรอก **เหตุผล / หมายเหตุ**
5. กด **บันทึกการแก้ไข** แล้วตรวจผล

แบบฟอร์มนี้แก้ได้เฉพาะสถานะ นาทีสาย การหักเงิน และหมายเหตุ **ยังไม่มีช่องแก้เวลาเข้า/ออก วันที่ หรือสาขา** หากข้อมูลเหล่านั้นผิดให้แจ้ง HR/ผู้ดูแล รอบที่ล็อกแล้วแก้วันทำงานด้วยวิธีปกติไม่ได้

## 8. ขอลา แก้ไขคำขอ และพิจารณาการลา

### 8.1 ส่งคำขอลา

1. เปิด **การลา**
2. Employee ตรวจชื่อของตนเอง ส่วนผู้จัดการเลือกพนักงานที่ต้องการทำรายการให้
3. กด **โหลดคำขอ** เพื่อตรวจคำขอเดิมก่อนสร้างซ้ำ
4. ส่วน **ส่งคำขอลาใหม่** เลือก **ประเภทการลา** จากรายการ
5. เลือก **วันลาเริ่มต้น** และ **วันลาสิ้นสุด** ถ้าลาหนึ่งวันให้เลือกวันเดียวกันทั้งสองช่อง
6. กรอกเหตุผลให้ผู้อนุมัติเข้าใจ
7. ติ๊ก **เป็นคำขอย้อนหลัง** เฉพาะกรณีเป็นการย้อนหลังจริง
8. กด **ส่งคำขอ**
9. ตรวจข้อความ **ส่งคำขอลาแล้ว** และสถานะรอพิจารณาในรายการ

ระบบนับวันตั้งแต่วันเริ่มจนวันสิ้นสุดรวมทั้งสองวัน เช่น 12–14 ต.ค. เป็น 3 วัน อย่าสันนิษฐานว่าระบบข้ามเสาร์อาทิตย์ให้อัตโนมัติ คำขอของคนเดียวกันมีวันซ้อนกันไม่ได้

ถ้าประเภทขึ้น “ต้องแนบเอกสาร” ให้แนบหลักฐาน PDF/PNG/JPEG ไม่เกิน 5 MB ผ่านรายการคำขอ ก่อนให้ผู้อนุมัติพิจารณา การกรอกเหตุผลไม่ทดแทนเอกสารที่ประเภทลาบังคับ

### 8.2 แก้คำขอที่ยังรอพิจารณา

1. โหลดคำขอของพนักงาน
2. กด **แก้ไขคำขอ** ใต้รายการรอพิจารณา
3. แก้ประเภท เหตุผล วันที่ หรือเครื่องหมายย้อนหลัง
4. กด **บันทึก** ถ้าไม่ต้องการเปลี่ยน กด **ยกเลิก** ซึ่งหมายถึงยกเลิกการแก้ฟอร์ม ไม่ใช่ถอนคำขอลาจากระบบ
5. ตรวจคำขอเดิมหลังบันทึก

คำขอที่ตัดสินแล้วไม่มีปุ่มแก้ผ่านวิธีนี้ หน้าเว็บยังไม่มีขั้นตอนถอนคำขอลา หากต้องถอนหรือแก้หลังอนุมัติให้ติดต่อ HR

### 8.3 พิจารณาคำขอ

**ผู้ใช้:** Supervisor, Branch Manager, HR, Owner

1. เลือกพนักงานในขอบเขต แล้วกด **โหลดคำขอ**
2. ตรวจวัน จำนวนวัน ประเภท เหตุผล และหลักฐานที่เกี่ยวข้อง
3. ถ้าต้องเปลี่ยนประเภท ใช้ **เปลี่ยนประเภทการลา (ถ้าจำเป็น)** ไม่เปลี่ยนให้คง **ใช้ประเภทเดิม**
4. กด **อนุมัติ** หรือกรอกหมายเหตุแล้วกด **ไม่อนุมัติ**
5. ตรวจสถานะใหม่

Supervisor อนุมัติได้ไม่เกิน 3 วัน หาก 4 วันขึ้นไปให้แจ้ง Branch Manager เพื่อเปิดคำขอเดียวกันมาพิจารณา **ยังไม่มีปุ่มส่งต่ออัตโนมัติ** ผู้จัดการสาขาอนุมัติได้ทุกจำนวนวันภายในสาขาของตน

หมายเหตุของการอนุมัติและการไม่อนุมัติถูกเก็บในประวัติการพิจารณา พร้อมผู้ดำเนินการและเวลา

การอนุมัติตรวจโควตาและปรับข้อมูลวันทำงานใน transaction เดียวกัน ตามกฎปัจจุบัน วันลาที่อนุมัติไม่ถูกหักเป็นการขาดงานหรือมาสายใน payroll ให้ตรวจรายการคำนวณก่อนล็อกงวดทุกครั้ง

## 9. ขอและพิจารณา OT

### 9.1 ส่งคำขอ

1. เปิด **ทำงานล่วงเวลา**
2. ตรวจชื่อของตนเอง หรือเลือกพนักงานในกรณีทำแทน
3. กด **โหลดคำขอ OT** ตรวจรายการเดิม
4. ใน **ส่งคำขอ OT ใหม่** เลือกวันที่ทำ OT
5. เลือกประเภทและกรอกหน่วยให้ตรง:

| ประเภท | ช่องที่กรอก | ตัวอย่าง |
|---|---|---|
| รายชั่วโมง | จำนวนชั่วโมง | `2.50` สำหรับ 2 ชั่วโมงครึ่ง |
| วันหยุดประจำสัปดาห์ | จำนวนวัน | `1.00` สำหรับหนึ่งวัน |
| วันหยุดนักขัตฤกษ์ | จำนวนวัน | `1.00` สำหรับหนึ่งวัน |

6. ถ้ามี **อ้างอิงรายการลงเวลา** ให้กรอก Work-day Record ID ที่ตรงวันและคน หากไม่ทราบให้เว้นว่างและขอคำแนะนำผู้ดูแล
7. กรอกเหตุผล แล้วกด **ส่งคำขอ**
8. ตรวจข้อความส่งคำขอและสถานะรอพิจารณา

ออกงานช้ากว่าปกติไม่ได้สร้าง OT ที่จ่ายให้อัตโนมัติ ต้องส่งคำขอและได้รับอนุมัติ หน้าเว็บปัจจุบันไม่มีแบบฟอร์มแก้/ถอนคำขอ OT หากกรอกผิดให้แจ้งผู้รับผิดชอบก่อนคำนวณเงินเดือน

### 9.2 พิจารณา OT

Supervisor/Branch Manager/HR/Owner เลือกพนักงาน → โหลดคำขอ OT → ตรวจวันที่ ประเภท จำนวนชั่วโมง/วัน และเหตุผล → กรอกหมายเหตุ → กด **อนุมัติ** หรือ **ไม่อนุมัติ** → ตรวจสถานะ รายการที่ตัดสินแล้วไม่ควรถูกสร้างซ้ำเพื่อแก้ยอด

## 10. เงินทดรอง เงินกู้ และหนี้

**ผู้ใช้หน้าเว็บ:** HR และ Owner Employee ยังไม่มีเมนูขอเงินทดรองด้วยตนเอง ให้ประสาน HR

เปิด **เงินทดรองและหนี้** → เลือกพนักงาน → กด **โหลดข้อมูลการเงิน** หน้าเดียวแบ่งเป็นเงินทดรองจ่าย เงินกู้ และบัญชีหนี้ หากโหลดบางส่วนล้มเหลว ยอด `0.00` ที่เห็นอาจเป็นค่าเริ่มต้น ไม่ใช่หลักฐานว่าไม่มีหนี้

### 10.1 เงินทดรองจ่าย

1. กรอกจำนวนเงิน เช่น `3000.00`
2. กด **ส่งคำขอเงินทดรองจ่าย**
3. ตรวจคำขอที่ปรากฏ
4. ผู้มีสิทธิ์กด **อนุมัติ** หรือ **ไม่อนุมัติ** ในรายการรอพิจารณา

วันที่ขอใช้วันที่ระบบ ไม่มีช่องเลือกย้อนหลัง ค่าพื้นฐานของกฎคือขอวันที่ 20 เป็นต้นไป ทำงานมาอย่างน้อย 20 วัน ยอดไม่เกินครึ่งเงินเดือนฐาน และหลังหักแล้วเงินสุทธิต้องไม่ติดลบ ผู้ดูแลอาจตั้งเกณฑ์ต่างออกไปได้

ตัวอย่างเงินเดือนฐาน `18000.00` เพดานครึ่งหนึ่งคือ `9000.00` แต่ไม่ได้หมายความว่าจะอนุมัติ 9,000 ได้ทุกครั้ง ต้องผ่านเกณฑ์วันทำงานและยอดสุทธิด้วย การกดอนุมัติคือบันทึกผลในระบบ ไม่ใช่หลักฐานโอนเงินจริง

### 10.2 เงินกู้แบบผ่อน

1. กรอก **ยอดเงินกู้**
2. กรอก **จำนวนงวด (1-5)**
3. เลือก **เดือนที่เริ่มชำระ**
4. กรอก **เหตุผล**
5. กด **สร้างเงินกู้**
6. ตรวจยอดคงเหลือ ตารางงวด เดือนครบกำหนด และยอดแต่ละงวด

ตัวอย่างกู้ `6000.00` ผ่อน 3 งวดเริ่ม พ.ย. 2026 ให้ตรวจตารางที่ระบบสร้าง ไม่ต้องสร้างคำขออีกหนึ่งรายการสำหรับแต่ละงวด หน้าเว็บไม่มีขั้นอนุมัติเงินกู้แยกหลังปุ่มสร้าง

### 10.3 บันทึกหนี้และกลับรายการ

1. ขอ **รหัสประเภทหนี้** ที่ถูกต้องจากผู้ดูแล ช่องนี้ยังเป็น ID ไม่มีรายการชื่อให้เลือก
2. เลือก **ประเภทรายการ**: เรียกเก็บ หรือปรับปรุง ตามคำแนะนำฝ่ายบัญชี
3. กรอกจำนวนเงินเป็นบวกและรายละเอียด
4. กด **บันทึกรายการ** แล้วตรวจยอดคงเหลือและรายการใหม่

ถ้ารายการผิดและยังไม่ถูกนำไปชำระในเงินเดือน ใช้ช่องเหตุผลข้างรายการ → กด **กลับรายการ** → ตรวจว่ามีรายการกลับรายการอ้างถึงรายการเดิม ประวัติเดิมยังคงอยู่

อย่าใส่จำนวนติดลบเพื่อหักล้าง เพราะฟอร์มรับจำนวนบวก อย่าลบหรือเริ่มบัญชีหนี้ใหม่เพื่อทำยอดให้เป็นศูนย์ รายการที่ชำระแล้วหรือกลับรายการแล้วจะไม่ให้กลับซ้ำผ่านปุ่มนี้

## 11. คำนวณและล็อกรอบเงินเดือน

**ผู้จัดการงาน:** HR และ Owner ผู้จัดการสาขาเข้าได้ในโหมดอ่านอย่างเดียว

### 11.1 เปิดสมุดงาน

1. เปิด **เงินเดือน**
2. เลือก **ร้าน**
3. กด **เปิดสมุดงาน** เพื่อโหลดค่าคำนวณและรอบของร้าน
4. ถ้ามีรอบเดิมแล้ว เลือกเดือนจากรายการ **รอบเงินเดือน** ไม่เปิดรอบซ้ำ

### 11.2 เตรียมค่าคำนวณ

เปิด **ความพร้อมของค่าคำนวณ** ตรวจค่าที่ขาด แล้วใช้ **เพิ่มค่าคำนวณแบบ effective-dated**:

1. เลือก **ค่าคำนวณ**
2. อ่าน **หน่วย** ที่ระบบแสดง
3. กรอก **ค่า** ตามนโยบายที่ฝ่ายบัญชียืนยัน
4. เลือก **เริ่มใช้** ให้ครอบคลุมช่วงที่จะคำนวณ
5. เลือกสาขา ถ้าใช้ทั้งร้านให้เลือก **ทั้งร้าน**
6. กด **บันทึกค่าคำนวณ** และตรวจแถวที่เพิ่ม

| ค่าคำนวณ | หน่วยที่หน้าจอใช้ |
|---|---|
| จำนวนวันทำงานมาตรฐาน | วัน |
| อัตราหักเมื่อขาดงาน | เท่าของค่าแรงรายวัน |
| อัตราหักเมื่อมาสาย | บาทต่อนาที |
| อัตรา OT รายชั่วโมง | เท่าของค่าแรงรายชั่วโมง |
| อัตรา OT วันหยุดประจำสัปดาห์ | เท่าของค่าแรงรายวัน |
| อัตรา OT วันหยุดนักขัตฤกษ์ | เท่าของค่าแรงรายวัน |
| อัตราประกันสังคม | สัดส่วน เช่น `0.0500` หมายถึง 5% เป็นตัวอย่างรูปแบบ ไม่ใช่การยืนยันอัตราที่ต้องใช้ |
| เพดานหักประกันสังคม | บาท |

มีค่าครบทั้งแปดชื่อไม่ได้รับรองว่าช่วงวันที่และขอบเขตถูกต้องทั้งหมด ตัว preview/lock จะตรวจเพิ่มเติม หน้าเว็บไม่มีแบบฟอร์มปิดช่วงหรือแก้ค่าคำนวณเดิม หากเพิ่มแล้วชนช่วงเดิม ให้ผู้ดูแลช่วยตรวจ ไม่เปลี่ยนวันที่เพื่อหลบข้อผิดพลาด

### 11.3 เปิดรอบใหม่

1. ส่วน **เปิดรอบเงินเดือน** เลือกเดือนที่ต้องการ
2. กด **เปิดรอบ**
3. ตรวจเดือน ปี วันเริ่ม และวันสิ้นสุด

หน้าจอสร้างช่วงจากวันแรกถึงวันสุดท้ายของเดือน หนึ่งร้านเปิดได้หนึ่งรอบต่อเดือน จึงไม่ใช่หน้าสำหรับเปิดรอบรายสัปดาห์หรือช่วงกำหนดเอง

### 11.4 คำนวณตัวอย่างและแก้สิ่งที่ขวางการล็อก

1. เลือกรอบที่ยังไม่ล็อก
2. กด **คำนวณตัวอย่าง**
3. ถ้าขึ้น **ยังล็อกรอบไม่ได้** ให้อ่านเหตุผลและแก้ข้อมูลต้นทาง
4. ตรวจรายได้ รายการหัก และสุทธิรายคน
5. กด **ดู … รายการ** ในคอลัมน์หลักฐาน เพื่อดูฐานเงินเดือน สวัสดิการ และรายการคำนวณ
6. ถ้ามีการแก้ข้อมูลต้นทาง ให้คำนวณตัวอย่างใหม่

| เหตุผล | งานที่ต้องตรวจ |
|---|---|
| ค่าคำนวณไม่ครบ | ค่าครบหรือไม่ วันที่เริ่มใช้และร้าน/สาขาครอบคลุมหรือไม่ |
| ข้อมูลลงเวลาไม่ครบ | วันทำงานในงวดของพนักงานที่ระบุ |
| ยังมีรายการรออนุมัติ | การลา OT เงินทดรอง หรือ Adjustment ที่เกี่ยวข้อง |
| ประวัติการสังกัดไม่ครบ | ประวัติการจ้างครอบคลุมวันที่ในรอบหรือไม่ |
| เงินสุทธิติดลบ | เงินทดรอง หนี้ ค่างวด และรายการหัก เทียบกับรายได้ |
| ยอดรวมไม่ตรงกัน | ให้ผู้ดูแลตรวจรายการและหลักฐานคำนวณ ไม่แก้ตัวเลขเดาสุ่ม |

ยอดสุทธิคือรายได้รวมลบรายการหัก ตัวอย่างรายได้ 19,000 และรายการหัก 1,200 จะเหลือ 17,800 แต่ยอดจริงต้องใช้รายละเอียดจากระบบ ไม่ใช้ตัวอย่างในคู่มือแทนการคำนวณ ประกันสังคมใช้ค่าจ้างพื้นฐานรวมรายวันในงวด ไม่รวมสวัสดิการ OT และรายการปรับปรุง ตาม policy ที่ยืนยัน ตัวอย่างทำงาน 27 วัน × 100 บาท ใช้ฐาน 2,700 บาท แม้เงินเดือนตามสัญญาเป็น 2,600 บาท

วันหยุดประจำสัปดาห์/นักขัตฤกษ์ที่ไม่ได้ทำงานไม่เพิ่มค่าจ้างจากการลง record วันหยุด หากทำงานจริงให้บันทึกมาทำงานหรือมาสาย และให้ผู้มีสิทธิ์อนุมัติ OT แยกตามประเภท

### 11.5 ล็อกรอบ

ก่อนล็อก ตรวจว่าข้อมูลวันทำงานครบ คำขอที่เกี่ยวข้องถูกพิจารณาแล้ว เงินสุทธิไม่ติดลบ และยอดรายคนเทียบหลักฐานแล้ว

1. กด **ล็อกรอบ**
2. อ่านข้อความยืนยันว่าผลคำนวณและรายการหักจะถูกตรึงเป็นประวัติ
3. ยืนยันเมื่อพร้อม
4. ตรวจข้อความสำเร็จและสถานะ **ล็อกแล้ว**

การล็อกไม่ใช่การโอนเงินธนาคาร หากมีข้อผิดพลาดหลังล็อก ห้ามแก้ข้อมูลเดิมให้ดูเหมือนถูกมาตั้งแต่แรก ใช้ Adjustment ตามบท 11.7

### 11.6 กลับมาเปิดรอบเดิม

เลือกร้าน เปิดสมุดงาน แล้วเลือกงวด ระบบโหลดผลที่บันทึกไว้พร้อมรายการหลักฐานและรายชื่อพนักงานตามประวัติการจ้าง การ refresh ไม่ลบผลที่บันทึกแล้ว งวดล็อกดูได้โดยไม่ต้องคำนวณซ้ำ

Branch Manager อ่านผลเฉพาะสาขาที่ได้รับสิทธิ์ ไม่มีปุ่มคำนวณหรือล็อก ถ้าไม่พบพนักงาน ให้ตรวจช่วงประวัติการจ้าง การผูก user กับสาขาเพียงอย่างเดียวไม่เพิ่มรายชื่อเงินเดือน

### 11.7 ขอปรับปรุงหลังล็อกรอบ

1. ไปส่วน **Adjustment หลังล็อกรอบ**
2. กรอก **Locked record ID** ของผลเงินเดือนรายคนที่ต้องแก้
3. กรอก **Target period ID** ของรอบที่จะนำส่วนต่างไปใช้
4. เลือกทิศทาง **เพิ่มรายได้** หรือ **เพิ่มรายการหัก**
5. กรอกจำนวนเงินและเหตุผล
6. กด **ส่ง Adjustment**

ตัวอย่างขาดรายได้ 500 บาทจากรอบเดิม ให้ขอเพิ่มรายได้ `500.00` ในงวดเป้าหมายที่ยังไม่ล็อก ผู้มีสิทธิ์พิจารณาได้จากรายการ Adjustment การส่งยังไม่ใช่การอนุมัติ รายการรอพิจารณาอาจขวางการล็อกงวดเป้าหมาย และยอดสุทธิติดลบล็อกไม่ได้

## 12. ดู ออก และจัดการสลิป

### 12.1 พนักงานดูสลิปของตนเอง

1. เปิด **สลิปเงินเดือน**
2. รอรายการสลิปของบัญชีโหลด
3. ดูวันที่ออกและยอดสุทธิ
4. ถ้าไม่มีสลิป ให้ถาม HR ว่าออกสลิปแล้วหรือยังและบัญชีเชื่อมพนักงานถูกต้องหรือไม่

Employee ดูรายการวันที่ออกและยอดสุทธิ พร้อมดาวน์โหลด PDF ของตนเอง เปิดหรือพิมพ์ไฟล์ PDF ได้

### 12.2 HR/Owner ออกสลิป

1. ยืนยันว่ารอบเงินเดือนล็อกแล้ว
2. เปิด **สลิปเงินเดือน**
3. เลือกร้าน งวดที่ล็อก และพนักงาน
4. กด **ออกหรือเปิดสลิป**
5. ตรวจสลิปที่เปิดขึ้น เลขสลิป รายการเงินเดือนอ้างอิง รายได้ รายการหัก และสุทธิ
6. เก็บ Payslip ID สำหรับเปิดดูภายหลัง

หนึ่งผลเงินเดือนมีได้หนึ่งสลิป หากเคยออกแล้ว ระบบเปิดสลิปเดิม ไม่สร้างเอกสารซ้ำ

### 12.3 เปิดสลิปเดิมและบันทึกการส่ง

1. เลือกร้าน งวด และพนักงาน แล้วกด **ออกหรือเปิดสลิป**
2. ตรวจว่าสลิปตรงพนักงาน/รายการเงินเดือนที่ต้องการ
3. กรอก **อีเมลผู้รับ** ให้ถูกบุคคล
4. กด **ส่งสลิป**
5. ตรวจรายการใหม่ใน **ประวัติการส่ง** แต่ละครั้งบันทึกแยกกัน

การส่งใช้ SMTP ที่ผู้ดูแลตั้งค่า สถานะ sent หมายถึง SMTP รับข้อความแล้ว ต้องตรวจ inbox เพิ่มเติม หาก pending เกิน 10 นาทีให้ตรวจ message ID กับ provider ก่อนบันทึกผล ห้ามส่งซ้ำโดยเดาว่าครั้งแรกไม่สำเร็จ

### 12.4 ยกเลิกสลิป

เปิดสลิป → กด **ยกเลิกสลิป** → อ่านและยืนยัน → ตรวจสถานะยกเลิก ประวัติการส่งเดิมยังอยู่ การยกเลิกไม่ได้ลบหรือแก้ผลเงินเดือน และไม่ควรคาดว่าจะออกสลิปใหม่สำหรับ record เดิมได้อัตโนมัติ ให้ประสานผู้ดูแลเรื่องการแก้ข้อมูล

## 13. ส่งออก CSV

**ผู้ใช้:** HR และ Owner CSV คือไฟล์ตารางที่เปิดด้วยโปรแกรมตารางคำนวณได้ ไม่ใช่คำสั่งโอนเงินหรือยื่นข้อมูลหน่วยงานโดยอัตโนมัติ

1. เปิด **รายงาน**
2. กรอก **รหัสรอบเงินเดือน** เป็น Payroll Period ID ของรอบที่ล็อกแล้ว ถ้าไม่ทราบขอจากผู้ดูแล
3. กด **ไฟล์โอนเงินธนาคาร (CSV)** หรือ **รายงานประกันสังคม (CSV)**
4. ระบบเปิดแท็บ/หน้าต่างใหม่ อาจดาวน์โหลดหรือแสดงข้อความไฟล์ตามเบราว์เซอร์
5. ตรวจเนื้อหาที่เปิดขึ้น ไม่ถือว่าข้อความ “กำลังเปิดไฟล์ CSV” แปลว่าส่งออกสำเร็จแล้ว

### 13.1 ตรวจไฟล์โอนเงิน

คอลัมน์ปัจจุบันคือ `bank_code`, `account_number`, `account_holder`, `net_pay` ให้ตรวจบัญชี ชื่อ และยอดกับรายชื่อผู้รับเงินทั้งรอบก่อนใช้

**หากพนักงานขาดบัญชีหลัก ระบบจะหยุดส่งออกทั้งไฟล์** ให้แก้ข้อมูลก่อนแล้วส่งออกใหม่ ไม่ข้ามผู้รับเงินเงียบ ๆ การส่งออกอ้างอิงบัญชีหลักที่ใช้อยู่ตอนส่งออก ต้องตรวจใหม่เมื่อมีการเปลี่ยนบัญชีภายหลังล็อกรอบ

ไฟล์มีเลขบัญชีเต็ม ให้เก็บในพื้นที่ฝ่ายบัญชีที่ควบคุมสิทธิ์ และตรวจรูปแบบที่ธนาคารรับก่อนนำเข้า เพราะเว็บยังไม่มีตัวเลือกแม่แบบธนาคารแต่ละแห่ง

### 13.2 ตรวจรายงานประกันสังคม

ไฟล์มีข้อมูลพนักงาน ฐานเงินเดือน และยอดหักประกันสังคมจากผลที่ล็อกแล้ว ฝ่ายบัญชีต้องตรวจและจัดรูปแบบตามกระบวนการที่ใช้ ยังไม่ใช่แบบยื่นสำเร็จรูป

หากได้ไฟล์เฉพาะหัวตาราง ให้ตรวจงวด สถานะล็อก และขอบเขตสิทธิ์กับผู้ดูแล การส่งออกอ่านรายการครบตามขอบเขตโดยไม่ตัดที่ 500 แถว

## 14. จัดการร้าน สาขา แผนก และตำแหน่ง

**ผู้ใช้:** HR และ Owner

ลำดับเตรียมข้อมูลคือ ร้าน → สาขา → แผนก ส่วนตำแหน่งอยู่ภายใต้ร้าน เตรียมก่อนเพิ่มพนักงาน

1. เปิด **โครงสร้างองค์กร**
2. เลือกประเภท **ร้าน / สาขา / แผนก / ตำแหน่ง**
3. เลือกสถานะและองค์กรแม่เพื่อดูรายการ
4. ไปแบบฟอร์ม **เพิ่ม…** ของประเภทนั้น
5. กรอกรหัสที่องค์กรกำหนดและชื่อ สำหรับสาขา/ตำแหน่งเลือกร้าน สำหรับแผนกเลือกสาขา
6. กรอกเขตเวลาหากฟอร์มแสดงช่องนี้ เช่น `Asia/Bangkok`
7. กดปุ่มเพิ่มและตรวจรายการ

**รหัส** ที่ตั้งเอง เช่น `BKK01` ไม่ใช่ Branch ID แบบตัวเลขที่หน้า Attendance ต้องใช้

เมื่อเลิกใช้รายการ กด **ปิดใช้งาน** ในรายการ → กรอกเหตุผล → ยืนยัน ระบบเก็บข้อมูลเดิมเพื่อประวัติ หากมีข้อมูลที่ใช้งานอ้างถึงอยู่ ระบบอาจปฏิเสธ ต้องตรวจงานที่เกี่ยวข้องก่อน ไม่สร้างรายการชื่อซ้ำเพื่อหลบข้อจำกัด

Owner สามารถเพิ่มร้านและสาขาจาก **การตั้งค่า → ตั้งค่าองค์กร** ได้ด้วย แบบฟอร์มกำหนดบทบาทใช้ตัวเลือกเดียวกับรายละเอียดบัญชี: Supervisor ต้องเลือกร้าน สาขา และแผนก; Branch Manager ต้องเลือกร้านและสาขา ส่วน HR/Owner ใช้ขอบเขตส่วนกลางตามสิทธิ์ของผู้กำหนด

## 15. จัดการบัญชีและสิทธิ์

**ผู้ใช้:** HR และ Owner บัญชีใหม่ต้องมีบทบาทและการเชื่อมพนักงานที่เหมาะสม ไม่ใช่สร้าง username แล้วใช้ทุกเมนูได้ทันที

### 15.1 สร้างบัญชี

1. เปิด **บัญชีผู้ใช้** ใช้ช่องชื่อผู้ใช้และสถานะค้นหาบัญชีเดิมก่อน
2. ไปหน้าสร้างบัญชีจากลิงก์ของทะเบียนบัญชี
3. กรอก **ชื่อผู้ใช้**
4. กรอก **รหัสพนักงาน** เป็น Employee ID ตัวเลข หากเป็นบัญชีเจ้าของที่ไม่เชื่อมพนักงานสามารถเว้นว่างได้
5. กด **สร้างบัญชี**
6. จัดเก็บรหัสผ่านชั่วคราวที่แสดงครั้งเดียว
7. กด **กำหนดบทบาทบัญชีนี้**

ถ้าบัญชียังไม่เชื่อมพนักงาน ให้ HR/Owner เปิดรายละเอียดบัญชี เลือกพนักงานที่ยังไม่มีบัญชีจากชื่อ/รหัส และบันทึกการเชื่อม ตรวจคนให้ตรงก่อนบันทึก ระบบป้องกันพนักงานคนเดียวถูกเชื่อมกับหลายบัญชี

### 15.2 เพิ่มบทบาทและขอบเขต

1. เปิดรายละเอียดบัญชี
2. ส่วน **เพิ่มบทบาท** เลือกบทบาท
3. ตรวจ **ขอบเขต** ที่ระบบแสดง
4. เลือกสาขา/แผนกเมื่อบทบาทต้องใช้
5. กรอกเหตุผลและกดปุ่มเพิ่มบทบาท
6. ตรวจรายการ **บทบาทและขอบเขต** หลังบันทึก

| บทบาท | ขอบเขตที่ต้องจัดเตรียม |
|---|---|
| Employee | self: เชื่อมแฟ้มพนักงานของบัญชี |
| Supervisor | department: เลือกสาขาและแผนกที่อยู่ในสาขานั้น |
| Branch Manager | branch: เลือกสาขา |
| HR | all: ทุกสาขา |
| Owner | all: ทุกสาขา ให้สิทธิ์ได้โดย Owner |

HR ไม่ให้หรือถอน Owner role แทน Owner ระบบป้องกันการถอนสิทธิ์หรือปิดบัญชีที่ทำให้ไม่เหลือ Owner ที่ใช้งานอยู่

### 15.3 ปลดล็อก รีเซ็ต และปิดบัญชี

เปิดรายละเอียดบัญชี → ส่วน **ความปลอดภัยบัญชี** → กรอก **เหตุผล** → เลือกการดำเนินการ:

- **ปลดล็อก:** ใช้เมื่อสถานะ locked และผู้ดูแลตรวจเหตุแล้ว
- **รีเซ็ตรหัสผ่าน:** รับรหัสชั่วคราวใหม่ จัดเก็บทันที และให้ผู้ใช้เปลี่ยนเองเมื่อเข้าได้
- **ปิดใช้งาน:** หยุดการใช้งานบัญชี ไม่ใช่การสิ้นสุดการจ้างของแฟ้มพนักงาน
- **เปิดใช้งาน:** เปิดบัญชีที่ปิดไว้เมื่อได้รับอนุญาต
- **ถอนบทบาท:** ใช้ในส่วนบทบาทและขอบเขต ตรวจรายการที่จะถอนให้ถูกต้อง

แจ้งเจ้าของบัญชีให้เข้าสู่ระบบใหม่เมื่อต้องตรวจเมนูหลังเปลี่ยนสิทธิ์ และอย่าเข้าใช้งานด้วยบัญชีของคนอื่นเพื่อตรวจสิทธิ์แทนการให้ผู้ใช้ทดสอบเอง

## 16. ตรวจประวัติการเปลี่ยนแปลง

**ผู้ใช้:** HR และ Owner ใช้ตรวจเหตุการณ์ ไม่ใช่หน้าแก้ข้อมูลหรือย้อนคืนรายการ

1. เปิด **ประวัติการเปลี่ยนแปลง**
2. กรองเฉพาะข้อมูลที่ทราบ เช่น ช่วงเวลา หรือ **Request ID** ที่ได้จากเหตุการณ์
3. หากใช้การดำเนินการ ชื่อตาราง รหัสรายการ หรือรหัสบัญชี ให้ใช้ค่าตรงกับระบบ ไม่ใช่คำแปลไทยหรือชื่อบุคคล
4. กด **ค้นหาประวัติ**
5. ตรวจเวลา บัญชีผู้ทำ การดำเนินการ เป้าหมาย เหตุผล และ Request
6. เปิด **ข้อมูลเดิม / ข้อมูลใหม่** หากต้องเทียบรายละเอียด
7. ใช้ **หน้าก่อน / หน้าถัดไป** หน้าละไม่เกิน 20 รายการ

ตัวกรองใช้ค่าตรงกันทั้งหมด หากไม่พบ ให้ลดเงื่อนไขก่อน ไม่ใส่ทุกช่องโดยเดาค่า หากพบข้อมูลลับในประวัติ ให้แจ้งผู้ดูแลและหลีกเลี่ยงส่งต่อภาพนั้น

## 17. ตัวอย่างงานตั้งแต่เริ่มจนจบรอบ

### 17.1 วันแรกที่องค์กรเริ่มใช้

1. ผู้ดูแลทางเทคนิคเปิดระบบและจัดเตรียมบัญชี Owner เริ่มต้น เว็บไม่ใช่หน้าสมัคร Owner แบบสาธารณะ
2. Owner เข้าสู่ระบบและเปลี่ยนรหัสผ่าน
3. Owner/HR เพิ่มร้าน สาขา แผนก และตำแหน่ง
4. HR เพิ่มพนักงานพร้อมการจ้าง วันหยุด และบัญชีรับเงิน
5. HR/Owner สร้างหรือยืนยันบัญชีผู้ใช้ การเชื่อมพนักงาน และบทบาทแต่ละคน
6. ผู้ใช้เข้าสู่ระบบ ตรวจขอบเขตและเปลี่ยนรหัสผ่านชั่วคราว
7. HR/Owner เตรียมค่าคำนวณและเปิดรอบเงินเดือน
8. ผู้ดูแลเตรียมตารางงาน ตารางเฉพาะวัน และวันหยุดนักขัตฤกษ์ผ่านเมนูตารางสาขา และกำหนดประเภทลา/โควตาผ่านหน้าจัดการการลา ตรวจวันที่เริ่มมีผลให้ครอบคลุมงวดที่จะคำนวณ

### 17.2 ตัวอย่างพนักงานลาหนึ่งวัน

พนักงานเปิดการลา → ตรวจชื่อ → โหลดคำขอ → เลือกประเภท → ใส่วันเดียวกันในเริ่มต้น/สิ้นสุด → ใส่เหตุผล → ส่ง → หัวหน้าเปิดคำขอคนเดียวกันและอนุมัติ → พนักงานโหลดคำขออีกครั้งเพื่อตรวจผล

ถ้าพนักงานขอ 4 วัน หัวหน้าแผนกแจ้งผู้จัดการสาขาให้พิจารณารายการเดิม ไม่แบ่งคำขอเพื่อหลบข้อจำกัดการอนุมัติ

### 17.3 งานประจำวันของผู้ดูแลทีม

1. ตรวจคนและวันที่ที่รับผิดชอบ
2. บันทึกวันทำงานให้ครบ และแก้ข้อมูลผิดก่อนล็อกรอบ
3. ตรวจคำขอลา/OT เป็นรายพนักงาน เพราะหน้าเว็บยังไม่มีกล่องงานรออนุมัติรวมทั้งทีม
4. พิจารณาคำขอที่มีหลักฐานครบ
5. แจ้ง HR เรื่องข้อมูลที่เกินสิทธิ์หรือแบบฟอร์มแก้ไม่ได้

### 17.4 ก่อนและหลังปิดเดือนของ HR

1. ตรวจประวัติการจ้าง เงินเดือน สวัสดิการ วันหยุด และบัญชีหลัก
2. ตรวจ Attendance และพิจารณาคำขอที่เกี่ยวข้องให้ครบ
3. ตรวจเงินทดรอง เงินกู้ ตารางงวด และหนี้
4. เปิดเงินเดือน เลือกร้าน/รอบ และคำนวณตัวอย่าง
5. แก้ blocker จากต้นทาง แล้วคำนวณใหม่
6. เทียบรายได้ รายการหัก และสุทธิรายคนกับหลักฐาน
7. ล็อกรอบเมื่อข้อมูลถูกต้อง
8. เปิดหน้าสลิป เลือกร้าน งวด และพนักงานจากรายการที่ล็อกแล้ว
9. ออกสลิป ตรวจ PDF และผู้รับ แล้วส่งผ่าน SMTP ตรวจ attempt และ inbox ตามกระบวนการองค์กร
10. ส่งออก CSV ตรวจจำนวนพนักงาน บัญชี และยอดก่อนดำเนินการจ่ายเงินจริง
11. เก็บหลักฐานการจ่ายและแจ้งผู้ดูแลเมื่อพบส่วนต่างที่ต้องใช้ Adjustment

## 18. แก้ปัญหาที่พบบ่อย

| อาการ | ตรวจหรือดำเนินการ |
|---|---|
| ไม่มีเมนูที่ต้องใช้ | ตรวจบทบาทและ scope กับ HR/Owner ไม่ใช้บัญชีคนอื่น |
| ชื่อผู้ใช้/รหัสผ่านไม่ถูกต้อง | ตรวจตัวสะกด ภาษาแป้นพิมพ์ และรหัสล่าสุดหลังรีเซ็ต |
| บัญชีถูกพัก/locked | รอหรือติดต่อผู้ดูแลให้ตรวจและปลดล็อก |
| เข้าไม่ได้หลังปิดใช้งาน | ให้ผู้ดูแลตรวจสถานะบัญชี ไม่ใช่แค่สถานะพนักงาน |
| บัญชียังไม่เชื่อมข้อมูลพนักงาน | ให้ผู้ดูแลเชื่อม Employee ID ที่ตรงคน |
| พิมพ์ชื่อแล้วกดบันทึกไม่ได้ | เลือกรายการแนะนำจนขึ้น “เลือกพนักงานแล้ว” |
| รายการว่างใน Leave/OT/Attendance | เลือกพนักงาน กดโหลด และตรวจช่วงวัน/ขอบเขต |
| สร้างวันทำงานไม่ได้เพราะซ้ำ | โหลดรายการเดิมและใช้ฟอร์มแก้ไข |
| แก้เวลาเข้า/ออกไม่ได้ | เลือกรายการในฟอร์มแก้ไข กรอกเวลาและเหตุผล หากรอบล็อกแล้วต้องใช้รายการปรับปรุงเงินเดือน |
| ลาอนุมัติไม่ได้ | ตรวจจำนวนวัน สิทธิ์ ช่วงซ้อน โควตา และรอบล็อกตามข้อความ error |
| ไม่มีประเภทลา/องค์กรให้เลือก | ให้ผู้ดูแลตรวจ master data ที่เปิดใช้งานและสิทธิ์ |
| เงินเดือนฐานกรอกไม่ผ่าน | ใช้ทศนิยม 2 ตำแหน่ง เช่น `18000.00` ไม่ใส่ comma |
| ขอเงินทดรองไม่ได้ | ตรวจวันที่ขอ เกณฑ์วันทำงาน ยอดเงิน เพดานและเงินสุทธิ |
| ล็อกเงินเดือนไม่ได้ | อ่าน blocker และแก้ต้นทาง ไม่กดล็อกซ้ำโดยไม่แก้ |
| รอบล็อกแล้วแต่เปิดใหม่ตารางว่าง | ข้อจำกัดการโหลดผลในหน้าเว็บ ดูบท 11.6 และให้ผู้ดูแลช่วย |
| ไม่ทราบ ID สำหรับสลิป/รายงาน | ขอชนิด ID ที่ถูกต้องจากผู้ดูแล ไม่ใช้รหัสพนักงานแทน |
| Employee ไม่เห็นสลิป | ตรวจว่า HR ออกสลิปแล้วและบัญชีเชื่อมถูกคน |
| บันทึกส่งสลิปแล้วแต่ไม่ได้อีเมล | ตรวจ attempt และการตั้งค่า SMTP; สถานะส่งแล้วหมายถึง SMTP รับข้อความ ตรวจ inbox/spam ของผู้รับด้วย |
| เปิด CSV ไม่ได้ | ตรวจการเปิดแท็บใหม่ session สิทธิ์และรหัสรอบ ดูข้อความที่แท็บรายงาน |
| CSV ไม่มีพนักงานบางคน | ตรวจงวดและขอบเขตสิทธิ์; บัญชีธนาคารหลักไม่ครบจะบล็อกการส่งออกพร้อมแจ้งเหตุผล |
| CSV มีแต่หัวตาราง | ให้ผู้ดูแลตรวจว่ารหัสรอบตรงกับรอบล็อกที่มี records |
| บันทึกสำเร็จแต่รายการไม่ปรากฏ | โหลดข้อมูลใหม่ ตรวจคนและช่วงวันก่อนสร้างซ้ำ |
| เชื่อมต่อไม่ได้ | ตรวจอินเทอร์เน็ต ลองโหลดหน้าใหม่ ถ้ายังไม่ได้แจ้งผู้ดูแล |

เมื่อขอความช่วยเหลือ ส่งชื่อหน้า งานที่ทำ วัน/เวลา ข้อความ error บทบาท สาขา/แผนก และ Request ID ถ้าแสดงอยู่ ไม่ส่งรหัสผ่าน เลขบัญชีเต็ม หรือเลขบัตรประชาชนเต็มในแชต หากต้องส่งภาพให้ปกปิดก่อน

## 19. ข้อจำกัดของเว็บปัจจุบัน

รายการนี้มีไว้ช่วยให้ผู้ใช้รู้ว่าเมื่อไรควรประสานผู้ดูแล ไม่ต้องหาปุ่มที่ยังไม่มี:

- Employee ขอเงินทดรองและดูข้อมูลการเงินตนเองได้ แต่ยังไม่มีหน้า Attendance แบบ self-service
- แนบ/ดาวน์โหลด PDF/PNG/JPEG ของพนักงานและคำขอลาได้ ไม่เกิน 5 MB ต่อไฟล์
- ตารางสาขา ตารางเฉพาะวัน วันหยุดนักขัตฤกษ์ และโควตาลามีหน้าจัดการตามสิทธิ์
- Leave/OT แสดงประวัติการพิจารณาได้ แต่ยังไม่มีกล่องรวมคำขอทั้งทีม
- คำขอ OT ที่ยังรอพิจารณาแก้ไขได้ ส่วนปุ่มถอนคำขอยังไม่อยู่ใน flow
- หมายเหตุอนุมัติลาถูกเก็บในประวัติแล้ว
- แก้เวลาเข้า/ออกและสถานะ Attendance ได้ วันที่และสาขาเป็นข้อมูลประวัติที่ไม่แก้ทับผ่านฟอร์มนี้
- HR/Owner แก้ข้อมูลติดต่อและสถานะในหน้าแฟ้มได้ การสิ้นสุดการจ้างต้องระบุวันทำงานสุดท้ายและเหตุผล โดยรักษาประวัติการจ้างเดิม
- Payroll โหลดผลที่บันทึกไว้เมื่อเปลี่ยนงวดหรือเปิดหน้าใหม่ พร้อม checklist ความพร้อมตามช่วงวันที่
- Adjustment มีรายการ ขอ อนุมัติ และปฏิเสธได้ รายการที่อนุมัติถูกนำเข้าการคำนวณงวดปลายทางและใช้ครั้งเดียวเมื่อล็อก โดยไม่แก้ snapshot งวดต้นทาง
- Employee ดาวน์โหลด PDF สลิปของตนเองได้
- การส่งสลิปใช้ SMTP จริงและบันทึกทุก attempt ต้องตั้งค่า connection และตรวจ inbox ของ provider จริงก่อนเปิดใช้
- รายงานมีสรุปลงเวลา ลา OT หนี้ และเงินเดือน พร้อมกรองสาขา/แผนก ดูรายละเอียดและส่งออกสรุป CSV
- CSV ประกันสังคมมียอดหักจากผลที่ล็อกแล้ว แต่ไม่ใช่แบบยื่นสำเร็จรูป
- CSV โอนเงินหยุดส่งออกหากพนักงานขาดบัญชีหลัก ไม่ข้ามพนักงานเงียบ ๆ และไม่จำกัดผลไว้ที่ 500 แถว
- เลือกร้าน สาขา พนักงาน และงวดจากชื่อได้ใน flow หลัก
- เมนูมือถือมีปุ่มออกจากระบบ หากเชื่อมต่อไม่สำเร็จจะแสดงข้อผิดพลาดและให้ลองใหม่
- ยังไม่มีการเชื่อมเครื่องลงเวลาภายนอกหรือ OCR ใน workflow ผู้ใช้

สิ่งที่ใช้งานผ่านเว็บได้แล้วใน checkout นี้คือ **เปลี่ยนรหัสผ่านเองในหน้า “การตั้งค่า” ทุกบทบาท** จึงไม่ต้องขอผู้ดูแลรีเซ็ตเพียงเพื่อเปลี่ยนรหัสที่ยังจำได้
