## การปรับระบบและประเด็นที่ต้องปรับเอกสาร

แก้หน้าค้นหาพนักงานให้โหลดตัวเลือกองค์กรเป็นชุดเพื่อรองรับร้านจำนวนมาก ปรับ CSS ส่วนข้อมูลพนักงานและตรวจหน้าจอมือถือ ปรับการเลือกประเภทรับเงินและสรุปเงินเดือนตามสาขา พร้อมอัปเดตคู่มือผู้ใช้ การดำเนินการเหล่านี้ผ่านการทดสอบในระบบแยกตามหลักฐานข้างต้น

UC10–14 ใน DOCX ควรแก้ให้ระบุว่าพนักงานเลือกประเภทรับเงินเป็นเงินสด เงินโอน PromptPay หรือประกันสังคมได้ โดย HR และเจ้าของแก้แทนได้ ประเภทประกันสังคมจ่ายเงินเดือนสุทธิเข้าบัญชีธนาคาร และแยกจากสถานะสมาชิกที่ใช้คำนวณเงินสมทบ หน้าจ่ายแสดงจำนวนคนและเงินเดือนสุทธิที่ต้องจ่ายแต่ละประเภทแยกสาขา ผู้ใช้บันทึกการจ่ายหลังดำเนินการภายนอก ระบบไม่ได้โอนเงินจริง ยอดประเภทประกันสังคมในหน้าจ่ายไม่ใช่ยอดเงินสมทบ

Migration `0007_payment_category` เพิ่มประเภทและ snapshot โดยไม่เขียนทับข้อมูลเดิม การทดลองบนฐานแยกตรวจ fingerprint รายการจ่ายเดิม 527 แถวก่อนและหลังตรงกัน; test ตรวจการบังคับบัญชีธนาคารและ snapshot ที่แก้ไม่ได้ผ่าน ข้อมูลเก่าที่ยังไม่เลือกประเภทยังจัดกลุ่มตามกฎเดิมจนกว่าจะเลือกและบันทึก ยังไม่ได้นำ migration ไปใช้กับฐานจริง

การปรับเอกสาร DOCX ยังคงเป็นข้อเสนอ ไม่ได้แก้ไฟล์ต้นฉบับ รายการทางเลือกที่เอกสารไม่ระบุชัด เช่น ช่วงรอบเงินเดือนแบบกำหนดเอง ต้องให้ผู้ใช้ตัดสินใจหากต้องการพฤติกรรมนอกเหนือจากรอบเต็มเดือนที่เว็บใช้
