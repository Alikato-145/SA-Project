# คู่มือใช้งาน Haris Payroll สำหรับผู้เริ่มต้น

คู่มือนี้อธิบายการใช้งานผ่านหน้าจอเว็บตามกลุ่มงานของระบบ ชื่อเมนู ปุ่ม และช่องกรอกในเครื่องหมาย **ตัวหนา** เป็นชื่อที่ใช้ในหน้าจอ ตัวอย่างชื่อ วันที่ และจำนวนเงินเป็นข้อมูลสมมติ ให้ใช้ข้อมูลจริงที่ HR อนุมัติเมื่อทำงานจริง หมายเลข UC ในหัวข้อคู่มือนี้เป็นชุดเดิมและแตกต่างจากรายงานฉบับล่าสุด ให้ใช้ตารางด้านล่างค้นหาขั้นตอนตามหมายเลขในรายงาน

## เริ่มจากศูนย์

1. ขอ **ที่อยู่เว็บของระบบ** และ **ชื่อผู้ใช้/รหัสผ่าน** จากผู้ติดตั้งหรือ HR/เจ้าของร้าน ไม่มีรหัสผ่านกลางสำหรับทุกคน
2. เปิดที่อยู่เว็บใน browser แล้วกรอก **ชื่อผู้ใช้** และ **รหัสผ่าน** กด **เข้าสู่พื้นที่ทำงาน** ดู [UC01](#uc01-เข้าสู่ระบบและจัดการรหัสผ่าน)
3. หน้า **ภาพรวม** แสดงลิงก์ **เริ่มงานประจำวัน** และ sidebar ตามสิทธิ์ของบัญชี กดชื่อเมนูใน sidebar เพื่อไปหน้านั้น การไม่เห็นเมนูหรือเห็น **คุณเปิดส่วนงานนี้ไม่ได้** มักหมายถึงยังไม่ได้รับบทบาท/ขอบเขตที่เหมาะสม ให้ HR/เจ้าของตรวจ [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้) อย่าใช้บัญชีคนอื่นเพื่อข้ามสิทธิ์
4. หน้าที่มีตัวเลือก **ร้าน** ให้เลือกร้านก่อน แล้วเลือก **สาขา** ที่อยู่ในร้านนั้น; บางหน้าต้องกด **เปิดสมุดงาน** หรือ **โหลดตารางและวันหยุด** จึงจะเห็นข้อมูล ตัวเลือก **พนักงาน** สำหรับผู้ดูแลให้พิมพ์ชื่อหรือรหัสใน **ค้นหาชื่อหรือรหัสพนักงาน** แล้วเลือกข้อเสนอในรายการ ส่วนหน้าของพนักงานทั่วไปผูกกับทะเบียนของตนเองอยู่แล้ว
5. การเลือกตัวกรองอย่างเดียวอาจยังไม่โหลดรายการ กดปุ่ม **โหลดรายการ**, **โหลดคำขอ**, **โหลดคำขอ OT** หรือ **โหลดข้อมูลการเงิน** ตามหน้า เมื่อบันทึกหรืออนุมัติแล้ว ให้กดโหลดอีกครั้งหรือ reload หน้าเพื่อตรวจข้อมูลที่เก็บจริง ข้อความ “รอพิจารณา” หมายถึงยังไม่อนุมัติ

| บทบาทที่บัญชีได้รับ | ขอบเขตงานหลัก |
|---|---|
| พนักงาน (EMPLOYEE) | ข้อมูล การลงเวลา คำขอ และสลิปของตนเอง เมื่อบัญชีเชื่อมทะเบียนพนักงานและมี grant แบบ self |
| หัวหน้าแผนก (SUPERVISOR) | งานพนักงานในแผนกและสาขาที่กำหนด รวมถึงพิจารณาลาได้ไม่เกิน 3 วันต่อคำขอ |
| ผู้จัดการสาขา (BRANCH_MANAGER) | งานพนักงานในสาขาที่กำหนด พิจารณาลาได้ทุกระยะ และจัดการตาราง/ข้อมูลพื้นฐานพนักงานในสาขาตน |
| HR | งาน HR และการเงินทุกสาขา รวมถึงงานบัญชีสำหรับการส่งมอบนี้ |
| เจ้าของร้าน (OWNER) | ทุกสาขา รวมถึงการจัดการ grant ระดับเจ้าของ |

บทบาทกับขอบเขตเป็นคนละส่วน: มีบทบาทหัวหน้าแผนกแต่ไม่ได้กำหนดสาขา/แผนกให้ถูกต้องก็จะไม่เห็นพนักงานนั้น **ไม่มีบทบาท ACCOUNTING แยก**; เจ้าหน้าที่บัญชีใช้สิทธิ์ HR ที่ได้รับ

### ลำดับแนะนำและสิ่งที่ต้องมี

ทำตามลำดับงาน ไม่จำเป็นต้องทำตามเลข UC: ใช้บัญชี HR/เจ้าของที่ผู้ติดตั้งมอบให้เข้า [UC01](#uc01-เข้าสู่ระบบและจัดการรหัสผ่าน) → ตั้ง [UC02](#uc02-จัดการโครงสร้างองค์กร) → สร้างทะเบียนพนักงาน [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน) → จึงเชื่อมบัญชีพนักงานและให้ self grant ใน [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้) → ตั้ง [UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา) และ [UC06](#uc06-กำหนดนโยบายเงินเดือนและการลา) จากนั้นงานประจำวัน [UC07](#uc07-บันทึกและแก้ไขข้อมูลลงเวลา) → [UC08](#uc08-ยื่นคำขอลา)/[UC09](#uc09-พิจารณาคำขอลา) → [UC10](#uc10-ยื่นและแก้ไขคำขอทำงานล่วงเวลา)/[UC11](#uc11-พิจารณาคำขอทำงานล่วงเวลา) → [UC12](#uc12-จัดการคำขอเงินทดรองและเงินกู้) และ [UC13](#uc13-บันทึกหนี้และรายการปรับปรุงเงินเดือน) ปิดงวดด้วย [UC14](#uc14-เปิดงวดเงินเดือน) → [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน) → [UC16](#uc16-ตรวจความพร้อมและล็อกรอบเงินเดือน) → [UC17](#uc17-ออกและส่งสลิปเงินเดือน) และ [UC18](#uc18-เตรียมและบันทึกการจ่ายเงินเดือน-พร้อมรายงานและไฟล์จ่าย) ใช้ [UC19](#uc19-ดูภาพรวมและรายงานตามสิทธิ์) และ [UC20](#uc20-ตรวจสอบประวัติการดำเนินงาน) เพื่อตรวจงานตามสิทธิ์

เช็กลำดับก่อนปิดงวด: มีร้าน/สาขา/แผนก/ตำแหน่ง → ประวัติการจ้าง เงินเดือนฐาน สวัสดิการ สมาชิกประกันสังคม และปลายทางจ่ายถูกวันที่ → บัญชีพนักงานเชื่อมทะเบียนและ grant ถูก scope → ตารางและค่าคำนวณครอบคลุมวันทำงาน → ลงเวลาครบและคำขอลา/OT/เงินทดรอง/รายการปรับปรุงตัดสินแล้ว → preview ไม่มี blocker และยอดสุทธิไม่ติดลบ → จึงล็อกงวด

## UC01 เข้าสู่ระบบและจัดการรหัสผ่าน

**เป้าหมาย/ผู้ใช้:** ทั้งห้าบทบาทเข้าระบบของตนเองและเปลี่ยนรหัสผ่านของตนได้ **ต้องมี:** บัญชี active จาก [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้)

1. ที่หน้า login กรอก **ชื่อผู้ใช้**, **รหัสผ่าน** และกด **เข้าสู่พื้นที่ทำงาน**; reload หน้า **ภาพรวม** เพื่อตรวจว่ายังเข้าใช้งานด้วยบัญชีเดิมได้
2. เปิด **การตั้งค่า** → **รหัสผ่านของฉัน** กรอก **รหัสผ่านปัจจุบัน**, **รหัสผ่านใหม่**, **ยืนยันรหัสผ่านใหม่** แล้วกด **เปลี่ยนรหัสผ่าน**
3. เห็นข้อความ **เปลี่ยนรหัสผ่านเรียบร้อยแล้ว ใช้รหัสผ่านใหม่ในการเข้าสู่ระบบครั้งถัดไป**; session ที่ใช้อยู่ยังทำงานได้ กด **ออกจากระบบ** แล้วเข้าด้วยรหัสใหม่เพื่อตรวจ รหัสเดิมต้องใช้เข้าใหม่ไม่ได้ การออกจากระบบเพิกถอน token ของ session ปัจจุบันที่ถูกคัดลอกไว้ด้วย

**ติดขัด:** รหัสผ่านปัจจุบันผิดจะถูกปฏิเสธ ให้ตรวจการพิมพ์หรือขอ HR/เจ้าของรีเซ็ต; อย่าคาดว่าการเปลี่ยนรหัสผ่านจะออกจากทุกอุปกรณ์อัตโนมัติ **ต่อไป:** เปิด [UC19](#uc19-ดูภาพรวมและรายงานตามสิทธิ์)

## UC02 จัดการโครงสร้างองค์กร

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของสร้างร้าน สาขา แผนก และตำแหน่งที่นำไปใช้กับพนักงาน **ต้องมี:** [UC01](#uc01-เข้าสู่ระบบและจัดการรหัสผ่าน) และชื่อหน่วยงานที่ต้องการสร้าง

1. เปิด **โครงสร้างองค์กร** เลือก tab **ร้าน** กรอก **ชื่อ** ในฟอร์ม แล้วกด **เพิ่มร้าน** ระบบกำหนดรหัสให้อัตโนมัติ
2. เลือก tab **สาขา** เลือก **ร้าน** แม่ กรอก **ชื่อ** กด **เพิ่มสาขา**; ทำแบบเดียวกันใน tab **แผนก** โดยเลือก **สาขา** และ tab **ตำแหน่ง** โดยเลือกหน่วยงานแม่ตามหน้าจอ
3. ใช้ **ค้นหารหัสหรือชื่อ** เพื่อหารายการ กด **แก้ไข** ที่แถว แก้ **ชื่อ** แล้วกด **บันทึกการแก้ไข**; โหลดหน้าใหม่และค้นรหัสเดิมเพื่อยืนยันชื่อที่แก้

**ติดขัด:** ถ้า parent ไม่อยู่ในตัวเลือก ให้สร้าง parent ก่อนและตรวจว่าร้าน/สาขาอยู่ในสถานะใช้งาน; ระบบกำหนดรหัสให้อัตโนมัติ ใช้การปิดใช้งานแทนลบข้อมูลที่มีประวัติ **ต่อไป:** [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้), [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน)

## UC03 จัดการบัญชีและสิทธิ์ผู้ใช้

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของสร้างบัญชีและ grant ในขอบเขตที่ถูกต้อง; เจ้าของเท่านั้นจัดการ OWNER grant **ต้องมี:** [UC02](#uc02-จัดการโครงสร้างองค์กร); ถ้าจะให้ self grant ต้องมีทะเบียนพนักงานจาก [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน)

1. เปิด **บัญชีผู้ใช้** → **สร้างบัญชี** กรอก **ชื่อผู้ใช้** และเลือก **พนักงานที่เชื่อมกับบัญชี** เมื่อเป็นบัญชีของบุคคล กด **สร้างบัญชี** รับรหัสผ่านชั่วคราวที่แสดงครั้งเดียวและส่งให้เจ้าของบัญชีผ่านช่องทางที่ปลอดภัย
2. กด **กำหนดบทบาทบัญชีนี้** เลือก **บทบาท**, **ขอบเขต** แล้วเลือก **ร้าน**, **สาขา**, **แผนก** ตามบทบาท เช่น BRANCH_MANAGER เลือกสาขา, SUPERVISOR เลือกสาขาและแผนก, EMPLOYEE เลือก self ของพนักงานที่เชื่อม กรอก **เหตุผล** แล้วกด **เพิ่มบทบาท**
3. กลับ **บัญชีผู้ใช้** ค้นชื่อบัญชี เปิดรายละเอียด ตรวจ **บทบาทและขอบเขต** และพนักงานที่เชื่อม; reload แล้วยังต้องเห็น grant เดิม

**ติดขัด:** หาก self grant กดไม่ได้ ให้เชื่อมพนักงานก่อน; หากเลือกสาขา/แผนกไม่ได้ ให้ตรวจ [UC02](#uc02-จัดการโครงสร้างองค์กร) และการจับคู่ parent; เมนูของผู้ใช้ไม่ปรากฏให้ตรวจ grant และ scope ที่นี่ **ต่อไป:** [UC01](#uc01-เข้าสู่ระบบและจัดการรหัสผ่าน) สำหรับผู้ใช้ใหม่

## UC04 จัดการข้อมูลและประวัติพนักงาน

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของดูแลทุกสาขา; ผู้จัดการสาขาสร้าง แก้ข้อมูลติดต่อ และสิ้นสุดการจ้างเฉพาะสาขาตน แต่ไม่จัดการบัญชีธนาคาร/ค่าตอบแทนข้ามสาขา **ต้องมี:** [UC02](#uc02-จัดการโครงสร้างองค์กร) และวันเริ่มงานที่ถูกต้อง

**ค้นหาพนักงาน — UC06 ในรายงาน**

1. เปิดเมนู **พนักงาน** จากนั้นพิมพ์รหัสพนักงาน ชื่อ หรือนามสกุลในช่อง **ค้นหาชื่อหรือรหัสพนักงาน** หากต้องการจำกัดผล ให้เลือก **สถานะ**, **สาขา** หรือ **แผนก** ตามสิทธิ์
2. กด **ค้นหา** แล้วตรวจรายชื่อที่แสดง หากมีหลายหน้าใช้ **หน้าก่อน** และ **หน้าถัดไป** เลือกชื่อพนักงานเพื่อเปิดรายละเอียดที่บัญชีของคุณมีสิทธิ์ดู
3. หากไม่พบรายชื่อ ให้ตรวจคำค้นและตัวกรอง หรือเลือกตัวเลือกทุกสถานะ/ทุกสาขา/ทุกแผนกที่มีสิทธิ์ แล้วกด **ค้นหา** อีกครั้ง หากมีร้านหรือสาขาจำนวนมาก ชื่อในตัวเลือกอาจใช้เวลาโหลดสักครู่

**รับพนักงานใหม่**

1. เปิด **พนักงาน** → **เพิ่มพนักงาน** กรอก **วันที่เริ่มงาน**, **ชื่อ**, **นามสกุล** และข้อมูลยืนยันตัวตนตามฟอร์ม กด **ถัดไป** ระบบกำหนดรหัสพนักงานให้อัตโนมัติ
2. เลือก **ร้าน** → **สาขา** → **แผนก** → **ตำแหน่ง**, กรอก **เงินเดือนฐาน** และข้อมูลการจ้างอื่นที่ต้องใช้ ตัวอย่างสมมติ: เงินเดือนฐาน `18000.00` หากต้องการสร้างบัญชีพร้อมกัน ให้เลือก **สร้างบัญชีเข้าใช้งาน** กรอก **ชื่อผู้ใช้** และเลือก **บทบาทเริ่มต้น** (ค่าเริ่มต้นคือพนักงาน) แล้วกด **สร้างพนักงาน** บันทึกรหัสผ่านชั่วคราวที่แสดงครั้งเดียว
3. กด **ดูข้อมูลพนักงาน** ตรวจรหัสและสังกัด แล้ว reload หน้ารายละเอียด

**แก้ข้อมูลและสถานะ**

1. ในหน้าพนักงาน เปิด **แก้ข้อมูลติดต่อพนักงาน** ปรับ **โทรศัพท์** หรือ **อีเมลส่วนตัว** แล้วกด **บันทึกข้อมูลพนักงาน**
2. หากสิ้นสุดการจ้าง เปิด **เปลี่ยนสถานะพนักงาน** เลือก **สถานะใหม่** เป็น **สิ้นสุดการจ้าง** ใส่ **วันทำงานสุดท้าย** และ **เหตุผลเปลี่ยนสถานะ** กด **บันทึกสถานะพนักงาน**; reload ตรวจสถานะและประวัติ บัญชีที่เชื่อมกับพนักงานจะถูกปฏิเสธการเข้าสู่ระบบตั้งแต่เริ่มวันสิ้นสุดการจ้างตามเวลาไทย รวมถึง session ที่เปิดอยู่ ไม่ต้องปิดบัญชีแยก

**สร้างประวัติใหม่แทนแก้แถวเก่า — HR/เจ้าของ**

1. เปิดรายละเอียดพนักงาน → หน้าประวัติการจ้าง → **เพิ่มช่วงการจ้างใหม่** เลือก **ร้าน/สาขา/แผนก/ตำแหน่ง**, **ประเภทการจ้าง**, **เงินเดือนฐาน**, **สวัสดิการ**, **มีผลตั้งแต่** และสถานะ **สมาชิกประกันสังคมในช่วงการจ้างใหม่** กด **บันทึกช่วงใหม่** ตรวจช่วงเดิมสิ้นสุดก่อนช่วงใหม่และ reload
2. ในหน้าบัญชีธนาคาร ใช้ **เพิ่มบัญชีธนาคาร** กรอก **รหัสธนาคาร**, **ชื่อธนาคาร**, **ชื่อบัญชี**, **เลขบัญชีเต็ม** และเลือก **บัญชีหลัก** ตามต้องการ กด **เพิ่มบัญชี**; เมื่ออ่านกลับเลขบัญชีแสดงแบบปกปิด
3. ในหน้าวันหยุดประจำสัปดาห์ ใช้ **เพิ่มช่วงวันหยุด** เลือก **วันหยุด**, **มีผลตั้งแต่** กด **บันทึกช่วงใหม่**; หากเปลี่ยนวัน ให้สิ้นสุดช่วงเดิมแล้วสร้างช่วงใหม่ ตรวจวันที่ไม่ซ้อนกัน
4. ที่หน้ารายละเอียด **ช่องทางรับเงินเดือน** เลือก **วิธีรับเงินเดือน** เป็นเงินสด โอนเงิน หรือประกันสังคม หากเลือกโอนเงินให้กรอก **หมายเลขรับเงินพร้อมเพย์**; หากเลือกประกันสังคมให้ HR ตรวจบัญชีธนาคารหลัก กด **บันทึกช่องทางรับเงิน** เบอร์พร้อมเพย์แยกจาก **โทรศัพท์** ที่ใช้ติดต่อ พนักงานที่มีบัญชีเชื่อมทะเบียนสามารถเลือกช่องทางของตนได้ที่ **การตั้งค่า** → **ช่องทางรับเงินเดือน** เช่นกัน บัญชีเดิมที่ยังไม่เคยเลือกประเภทใหม่จะเห็นข้อความแจ้ง และยังใช้กลุ่มเดิมจนกว่าจะเลือกแล้วบันทึก

**ติดขัด:** ไม่มีสังกัด/ตำแหน่งให้เลือก → [UC02](#uc02-จัดการโครงสร้างองค์กร); ช่วงวันที่ซ้อนหรืออยู่ในงวดที่ล็อก → เลือกวันที่มีผลจริงและปรึกษา HR เรื่อง correction; ผู้จัดการสาขาไม่เห็นฟอร์มธนาคาร/ค่าตอบแทน → ให้ HR/เจ้าของทำ **ต่อไป:** [UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา), [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้)

## UC05 กำหนดตารางทำงานและวันหยุดสาขา

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของตั้งตารางและวันหยุดทุกสาขา; ผู้จัดการสาขาตั้งตารางเฉพาะสาขาตน **ต้องมี:** ร้าน/สาขาจาก [UC02](#uc02-จัดการโครงสร้างองค์กร)

1. เปิด **ตารางเวลาและวันหยุด** เลือก **ร้าน**, **สาขา** แล้วกด **โหลดตารางและวันหยุด** ระบบจะแสดงตารางที่มีผลในวันปัจจุบันตามเวลาไทย
2. ใน **เพิ่มหรือเปลี่ยนตารางเวลา** กรอก **เวลาเริ่มงาน**, **เวลาเลิกงาน**, **อนุโลมมาสาย (นาที)**, **เริ่มใช้วันที่** กด **บันทึกตารางเวลา** ตัวอย่างสมมติ 09:00–18:00 ผ่อนผัน 5 นาที
3. เมื่อเปลี่ยนตาราง เลือก **ตารางเดิมที่ต้องการเปลี่ยน** กรอกค่าและวันเริ่มใหม่ กด **บันทึกตารางเวลา**; ตรวจช่วงวันที่ของตารางแต่ละรายการในรายการตาราง
4. ถ้ามีวันพิเศษ ใช้ **ตารางเฉพาะวัน** ใส่ **วันที่เปลี่ยนตาราง** และ **เหตุผล**, เลือก **ปิดสาขา** หรือกรอกเวลาที่เปิด แล้วกด **บันทึกตารางเฉพาะวัน**; HR/เจ้าของเพิ่ม **วันหยุดนักขัตฤกษ์ของร้าน** โดยกรอก **วันที่หยุด**, **ชื่อวันหยุด** กด **เพิ่มวันหยุด**

**ติดขัด:** ปุ่มไม่พร้อมเมื่อยังไม่เลือกร้าน/สาขาหรือวันที่; วันหยุดนักขัตฤกษ์ไม่มีสำหรับผู้จัดการสาขา ให้ HR/เจ้าของตั้ง ค่า effective date ไม่ควรทับช่วงที่ใช้อยู่ **ต่อไป:** [UC07](#uc07-บันทึกและแก้ไขข้อมูลลงเวลา)

## UC06 กำหนดนโยบายเงินเดือนและการลา

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของกำหนดค่าคำนวณ ประเภทลา และสิทธิ์รายปี **ต้องมี:** [UC02](#uc02-จัดการโครงสร้างองค์กร), [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน) สำหรับสิทธิ์รายคน

**ค่าคำนวณเงินเดือน**

1. เปิด **เงินเดือน** เลือก **ร้าน** กด **เปิดสมุดงาน** เปิด **ตั้งค่าการคำนวณเงินเดือน**
2. เลือก **ค่าคำนวณ**, กรอก **ค่า**, **เริ่มใช้** และ **สาขา** ถ้าค่านั้นใช้เฉพาะสาขา (เว้นว่าง = ทั้งร้าน) กด **บันทึกค่าคำนวณ** หากเลือกอัตราประกันสังคมให้กรอกเป็นเปอร์เซ็นต์ เช่น กรอก `5` สำหรับ 5%
3. เมื่อเปลี่ยนค่า เปิด **ความพร้อมของค่าคำนวณ** → **เปลี่ยนค่าตั้งแต่วันที่** กรอก **ค่าใหม่**, **วันที่เริ่มใช้ค่าใหม่** กด **บันทึกช่วงใหม่**; reload ตรวจทั้งช่วงเก่าและใหม่

**ประเภทลาและสิทธิ์**

1. เปิด **การลา** → **จัดการประเภทและสิทธิ์วันลา (HR / เจ้าของ)** → **เพิ่มประเภทการลา** กรอก **รหัสประเภท**, **ชื่อประเภท**, เลือก **รูปแบบสิทธิ์** และ **จำนวนวันมาตรฐาน (สำหรับสิทธิ์คงที่)**; ตั้ง **หักค่าจ้าง** ตามนโยบายที่อนุมัติ (ลาที่อนุมัติและได้รับค่าจ้างไม่ต้องติ๊ก; ประเภทลาไม่รับค่าจ้างจึงติ๊ก) แล้วตั้ง **ต้องแนบเอกสารก่อนอนุมัติ** หรือ **อนุญาตเกินสิทธิ์ โดยส่วนเกินไม่ได้รับค่าจ้าง** ตามนโยบาย กด **บันทึกประเภท**
2. ใน **กำหนดสิทธิ์รายปี** เลือก **พนักงาน**, **ปี ค.ศ.**, **ประเภทการลา**, กรอก **สิทธิ์ทั้งหมด (วัน)** แล้วกด **บันทึกสิทธิ์วันลา** ตรวจ **สิทธิ์และยอดใช้ปี** และ reload

**ติดขัด:** ต้องมี config ครอบคลุมวันในงวดและช่วงใหม่ไม่ซ้อนกัน; ลาประเภทมี quota ต้องมีสิทธิ์รายปีที่ไม่ถูกล็อกใน **ทุกปี** ที่ช่วงลาครอบคลุม แม้ตั้งอนุญาตเกินสิทธิ์; เฉพาะรูปแบบ **ไม่จำกัดด้วยโควตา** ไม่ต้องมีแถวสิทธิ์ **ต่อไป:** [UC08](#uc08-ยื่นคำขอลา), [UC14](#uc14-เปิดงวดเงินเดือน)

## UC07 บันทึกและแก้ไขข้อมูลลงเวลา

**เป้าหมาย/ผู้ใช้:** พนักงานลงเวลาปกติของตนเมื่อมี active EMPLOYEE/self grant; หัวหน้าแผนก ผู้จัดการสาขา HR และเจ้าของทำตาม scope **ต้องมี:** [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้), [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน), ตารางที่มีผลจาก [UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา)

1. เปิด **ลงเวลา**; ผู้ดูแลเลือกพนักงานใน scope ด้วย **ค้นหาชื่อหรือรหัสพนักงาน** ส่วนพนักงานเห็นของตนเอง ใส่ **ตั้งแต่**, **ถึง** กด **โหลดรายการ** ตรวจ **ความครบถ้วนรายวัน**
2. ใน **บันทึกวันทำงาน** เลือก **วันที่ทำงาน** ตรวจ **สาขาตามประวัติการจ้าง** (เป็นสาขา ณ วันนั้น) และตารางที่แสดง กรอก **เวลาเข้างาน**, **เวลาออกงาน**, เลือก **สถานะ** ที่ตรงจริง แล้วกด **บันทึกวันทำงาน** หากเลือกมาทำงาน มาสาย 0 นาที และเว้นทั้งเวลาเข้าและออก ระบบใช้เวลาตามตารางสาขาที่มีผลในวันนั้น และระบุในรายการว่าไม่ได้กรอกเวลาจริง หากกรอกเพียงเวลาใดเวลาหนึ่ง ระบบจะไม่เติมอีกเวลาให้ พนักงานทำได้เฉพาะวันทำงานปกติ/มาสาย/ขาดงานแบบ manual; นาทีที่มาสายและการหักเงินคำนวณจากตาราง ตัวอย่าง: เข้างาน 09:20 กับตาราง 09:00 ผ่อนผัน 5 นาที จะแสดงสาย 15 นาที
3. แก้รายการเดิม: กด **โหลดรายการ** เลือก **รายการวันทำงาน** ใน **แก้ไขรายการ**, ปรับเวลา/สถานะ ใส่ **เหตุผล / หมายเหตุ** ที่บอกเหตุจริง แล้วกด **บันทึกการแก้ไข**; reload และโหลดช่วงวันเดิมเพื่อตรวจค่าใหม่และประวัติ

**ติดขัด:** ไม่มีสาขาหรือตารางที่มีผล → ให้ HR ตรวจประวัติการจ้าง/ตาราง; พนักงานแก้ได้เฉพาะแถว manual ปกติเดิมและต้องมีเหตุผลใหม่ที่มีความหมาย ห้ามแก้แถวลาอนุมัติ ข้อมูลนำเข้า หรือข้อยกเว้นวันหยุดเอง; งวดล็อกแล้วแก้ไม่ได้ ให้ใช้ [UC13](#uc13-บันทึกหนี้และรายการปรับปรุงเงินเดือน) สำหรับผลเงินเดือน **ต่อไป:** [UC08](#uc08-ยื่นคำขอลา), [UC10](#uc10-ยื่นและแก้ไขคำขอทำงานล่วงเวลา)

## UC08 ยื่นคำขอลา

**เป้าหมาย/ผู้ใช้:** พนักงานส่ง/แก้คำขอของตนเอง หรือหัวหน้าแผนก ผู้จัดการสาขา HR และเจ้าของส่งแทนพนักงานตามขอบเขตที่ได้รับ **ต้องมี:** บัญชีพนักงานเชื่อมทะเบียนจาก [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้), ประเภทและสิทธิ์จาก [UC06](#uc06-กำหนดนโยบายเงินเดือนและการลา)

หากส่งแทน ให้เปิด **การลา** แล้วพิมพ์ชื่อหรือรหัสใน **ค้นหาชื่อหรือรหัสพนักงาน** และเลือกพนักงานจากรายการก่อนกรอกคำขอ ตรวจชื่อที่เลือกให้ถูกต้อง พนักงานทั่วไปใช้ข้อมูลของตนเองโดยระบบเลือกให้

1. เปิด **การลา** → **ส่งคำขอลาใหม่** เลือก **ประเภทการลา**, กรอก **วันลาเริ่มต้น**, **วันลาสิ้นสุด**, **เหตุผล** และเลือก **เป็นคำขอย้อนหลัง** หากตรงกรณี กด **ส่งคำขอ**
2. กด **โหลดคำขอ** หรือ reload แล้วกดโหลด ตรวจรายการเป็น **รอพิจารณา**; ถ้ายังรอ สามารถกด **แก้ไขคำขอ** ปรับข้อมูล แล้วกด **บันทึก**
3. หากชื่อประเภทมี **(ต้องแนบเอกสาร)** ให้เปิด **เอกสารประกอบ** ในรายการคำขอลานั้น เลือก **ไฟล์เอกสาร** เป็น PDF, PNG หรือ JPEG ขนาดไม่เกิน 5 MB แล้วกด **แนบเอกสาร**; ตรวจข้อความ **แนบเอกสารแล้ว** และชื่อไฟล์ในรายการ หลัง reload ให้กด **โหลดคำขอ** และตรวจว่าไฟล์ยังอยู่ในคำขอเดียวกัน ก่อนส่งให้ผู้มีสิทธิ์อนุมัติ

**ติดขัด:** ข้อความ **สิทธิ์วันลาไม่เพียงพอหรือยังไม่ได้กำหนดสิทธิ์สำหรับปีที่ขอ** ให้ HR ตรวจสิทธิ์ทุกปีที่เกี่ยวข้องและว่าถูกล็อกหรือไม่; ช่วงวันซ้อนคำขอเดิมต้องเปลี่ยนวัน; การส่งและแก้ยังไม่จองหรือตัดสิทธิ์ การอนุมัติจะตรวจและใช้สิทธิ์อีกครั้ง จึงอาจไม่ผ่านหากสิทธิ์ถูกใช้ไประหว่างรอ ประเภทที่อนุญาตเกินสิทธิ์ให้ส่วนเกินเป็นลาไม่รับค่าจ้าง แต่ยังต้องมี quota ที่ไม่ถูกล็อก ยกเว้นประเภทไม่จำกัดด้วยโควตา **ต่อไป:** ผู้มีสิทธิ์ทำ [UC09](#uc09-พิจารณาคำขอลา)

## UC09 พิจารณาคำขอลา

**เป้าหมาย/ผู้ใช้:** หัวหน้าแผนกในแผนกตนอนุมัติได้ไม่เกิน 3 วันต่อคำขอ; ผู้จัดการสาขาในสาขาตนอนุมัติได้ทุกระยะและอนุมัติตรง; HR/เจ้าของตามสิทธิ์ทั่วทุกสาขา **ต้องมี:** คำขอรอจาก [UC08](#uc08-ยื่นคำขอลา) และ quota ที่ยังใช้ได้จาก [UC06](#uc06-กำหนดนโยบายเงินเดือนและการลา)

1. เปิด **การลา** เลือกพนักงานใน scope แล้วกด **โหลดคำขอ** ตรวจวัน ประเภท เหตุผล และถ้าประเภทกำหนด **ต้องแนบเอกสารก่อนอนุมัติ** ให้ตรวจชื่อไฟล์ใน **เอกสารประกอบ** ของคำขอนั้นก่อนตัดสิน
2. หากต้องแก้ประเภทก่อนตัดสิน เลือก **เปลี่ยนประเภทการลา (ถ้าจำเป็น)**; กรอก **หมายเหตุการพิจารณา** แล้วกด **อนุมัติ** หรือ **ไม่อนุมัติ**
3. โหลดคำขออีกครั้ง ตรวจสถานะและประวัติการพิจารณา; ให้พนักงาน reload หน้า **การลา** เพื่อตรวจผล

**ติดขัด:** ถ้าประเภทที่เลือกหรือเปลี่ยนตอนพิจารณาต้องมีเอกสารแต่ยังไม่มี ระบบไม่อนุมัติ ให้พนักงานกลับไปแนบไฟล์ที่ **เอกสารประกอบ** ของคำขอนั้นตาม [UC08](#uc08-ยื่นคำขอลา) แล้วกด **โหลดคำขอ** ตรวจไฟล์ก่อนอนุมัติอีกครั้ง; หัวหน้าเจอคำขอ 4 วันให้ผู้จัดการสาขา/HR/เจ้าของพิจารณา; quota หมด/ถูกล็อกระหว่างรอ ต้องให้ HR จัดการสิทธิ์หรือตัดสินไม่อนุมัติ; งวดล็อกแล้วไม่เปลี่ยนข้อมูลย้อนหลัง ทุกการตัดสินและการแก้ประเภทเก็บประวัติ **ต่อไป:** [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน)

## UC10 ยื่นและแก้ไขคำขอทำงานล่วงเวลา

**เป้าหมาย/ผู้ใช้:** พนักงานส่ง OT ของตนและแก้ขณะรอ **ต้องมี:** [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้), [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน), ตาราง/วันทำงานที่เกี่ยวข้องจาก [UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา)/[UC07](#uc07-บันทึกและแก้ไขข้อมูลลงเวลา)

1. เปิด **ทำงานล่วงเวลา** → **ส่งคำขอ OT ใหม่** กรอก **วันที่ทำ OT**, เลือก **ประเภท OT** เช่น **รายชั่วโมง**, วันหยุดประจำสัปดาห์ หรือวันหยุดนักขัตฤกษ์ตามเหตุจริง; กรอก **จำนวนชั่วโมง** หรือข้อมูลวันที่ที่ฟอร์มแสดง และ **เหตุผล** กด **ส่งคำขอ**
2. กด **โหลดคำขอ OT** หรือ reload แล้วโหลด ตรวจสถานะ **รอพิจารณา**; หากยังรอ กด **แก้ไขคำขอ** ปรับข้อมูล แล้วกด **บันทึก** และโหลดกลับ

**ติดขัด:** วันที่ไม่มี assignment/ตารางหรือไม่ตรงชนิด OT จะถูกปฏิเสธ ให้ตรวจ [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน)/[UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา); ออกงานช้าไม่ได้ทำให้ OT จ่ายอัตโนมัติ ต้องมีการอนุมัติใน [UC11](#uc11-พิจารณาคำขอทำงานล่วงเวลา) **ต่อไป:** [UC11](#uc11-พิจารณาคำขอทำงานล่วงเวลา)

## UC11 พิจารณาคำขอทำงานล่วงเวลา

**เป้าหมาย/ผู้ใช้:** หัวหน้าแผนก ผู้จัดการสาขา HR/เจ้าของพิจารณาภายใน scope **ต้องมี:** คำขอจาก [UC10](#uc10-ยื่นและแก้ไขคำขอทำงานล่วงเวลา)

1. เปิด **ทำงานล่วงเวลา** เลือกพนักงานใน scope กด **โหลดคำขอ OT** ตรวจวัน ชนิด ชั่วโมง และเหตุผล
2. ในรายการที่ **รอพิจารณา** กรอก **หมายเหตุการพิจารณา** แล้วกด **อนุมัติ** หรือ **ไม่อนุมัติ**
3. โหลดกลับตรวจสถานะ/ประวัติ ให้พนักงาน reload เพื่อตรวจผล; เฉพาะ OT ที่อนุมัติจึงเข้าสู่เงินเดือน

**ติดขัด:** ไม่เห็นคำขอ → ตรวจพนักงานและ scope; งวดล็อกแล้วหรือคำขอตัดสินไปแล้ว → ไม่แก้ย้อนหลังผ่านฟอร์มนี้ **ต่อไป:** [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน)

## UC12 จัดการคำขอเงินทดรองและเงินกู้

**เป้าหมาย/ผู้ใช้:** พนักงานยื่นของตน; HR/เจ้าของพิจารณาทุกสาขา **ต้องมี:** [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน), [UC07](#uc07-บันทึกและแก้ไขข้อมูลลงเวลา) สำหรับเกณฑ์วันทำงาน และเงินเดือนฐานที่มีผล

**เงินทดรองจ่าย**

1. พนักงานเปิด **เงินทดรองและหนี้** → **เงินทดรองจ่าย** กรอก **จำนวนเงิน**, **เหตุผลที่ขอเงินทดรองจ่าย** แล้วกด **ส่งคำขอเงินทดรองจ่าย** เหตุผลใหม่ต้องไม่ว่างหลังตัดช่องว่างและยาว 1–1,000 ตัวอักษร
2. กด **โหลดข้อมูลการเงิน** หรือ reload แล้วโหลด ตรวจเหตุผลและสถานะ **รอพิจารณา**
3. HR/เจ้าของเปิดหน้าเดียวกัน ค้นพนักงาน กด **โหลดข้อมูลการเงิน** ตรวจวันขอ จำนวน เหตุผล และยอดที่จะเหลือ แล้วกด **อนุมัติ** หรือกรอก **เหตุผลที่ไม่อนุมัติเงินทดรองจ่าย** 1–1,000 ตัวอักษรก่อนกด **ไม่อนุมัติ**; โหลดกลับตรวจผล และให้ผู้ยื่น reload ตรวจผล

**เงินกู้**

1. พนักงานใน **คำขอเงินกู้** กรอก **ยอดเงินที่ขอกู้**, **จำนวนงวดที่ขอ (1-5)**, **เหตุผลที่ขอกู้** กด **ส่งคำขอเงินกู้** แล้วโหลดกลับตรวจ **รอพิจารณา**
2. HR/เจ้าของค้นพนักงานและโหลดรายการ หากอนุมัติกรอก **เดือนเริ่มชำระ** แล้วกด **อนุมัติเงินกู้**; หากปฏิเสธกรอก **เหตุผลที่ไม่อนุมัติ** แล้วกด **ไม่อนุมัติเงินกู้** โหลดกลับตรวจผลและตารางผ่อนที่ปรากฏเมื่ออนุมัติ

**ติดขัด:** เงินทดรองทั่วไปขอได้ตั้งแต่วันที่ 20 ของเดือน ต้องมีวันทำงานอย่างน้อย 20 วัน วงเงินไม่เกินครึ่งเงินเดือนฐาน และการอนุมัติต้องไม่ทำให้ยอดสุทธิหลังหักติดลบ; อย่าบันทึกเวลาทำงานเท็จเพื่อผ่านเกณฑ์ เงินกู้เลือกได้ 1–5 งวด ผู้จัดการสาขา/หัวหน้าไม่ใช่ผู้อนุมัติการเงิน ประวัติเงินทดรองเก่าที่ไม่มีเหตุผลจะแสดงว่าไม่ได้บันทึกไว้ ไม่ควรเติมเหตุผลย้อนหลังเอง **ต่อไป:** [UC13](#uc13-บันทึกหนี้และรายการปรับปรุงเงินเดือน), [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน)

## UC13 บันทึกหนี้และรายการปรับปรุงเงินเดือน

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของบันทึกหนี้และส่วนต่างที่ตรวจสอบย้อนกลับได้ **ต้องมี:** พนักงานจาก [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน); รายการปรับงวดปัจจุบันต้องมีงวดเปิดจาก [UC14](#uc14-เปิดงวดเงินเดือน); การแก้งวดต้นทางต้องมีงวดล็อกจาก [UC16](#uc16-ตรวจความพร้อมและล็อกรอบเงินเดือน)

**หนี้**

1. เปิด **เงินทดรองและหนี้** เลือกพนักงาน กด **โหลดข้อมูลการเงิน**; หากยังไม่มีชนิดหนี้ เปิด **จัดการประเภทหนี้** กรอก **รหัสประเภท**, **ชื่อประเภท** กด **บันทึกประเภทหนี้**
2. ใน **บัญชีหนี้** เลือก **ประเภทหนี้**, ระบุประเภทรายการ จำนวนเงินและ **รายละเอียด** แล้วกด **บันทึกรายการ**; reload และโหลดดู ledger
3. ถ้ารายการผิดและยังกลับได้ ให้กรอก **เหตุผลการกลับรายการ** ที่รายการนั้น กด **กลับรายการ**; โหลดอีกครั้งจะเห็นรายการเดิมกับรายการกลับ ไม่ลบประวัติ

**เพิ่ม/หักในงวดปัจจุบัน**

1. เปิด **เงินเดือน** เลือก **ร้าน** กด **เปิดสมุดงาน** ใน **รายการเพิ่มและหักในงวดปัจจุบัน** เลือก **งวดเงินเดือน**, **พนักงานในงวด**, **ทิศทาง**, กรอก **จำนวนเงิน**, **เหตุผล** กด **ส่งรายการในงวดนี้**
2. ตรวจรายการเป็น pending แล้วกด **อนุมัติ** หรือ **ไม่อนุมัติ**; ที่อนุมัติจะขึ้น **อนุมัติแล้ว คำนวณงวดนี้เพื่อนำรายการไปใช้** ให้ทำ [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน) และ [UC16](#uc16-ตรวจความพร้อมและล็อกรอบเงินเดือน)

**แก้ผลของงวดที่ล็อกแล้ว**

1. เปิด **รายการปรับปรุงหลังล็อกรอบ** เลือก **ต้นทางที่ล็อกแล้ว**, **พนักงาน**, งวดปลายทางในร้านเดียวกัน, **ทิศทาง**, **จำนวนเงิน**, **เหตุผล** กด **ส่งรายการปรับปรุง**
2. ในประวัติรายการกด **อนุมัติ** หรือ **ไม่อนุมัติ**; reload ตรวจสถานะ **รอคำนวณและล็อกงวดปลายทาง** รายการจะนำไปใช้เมื่อล็อกงวดปลายทาง ไม่แก้ยอดเก่าที่ล็อกแล้ว

**ติดขัด:** ไม่มีพนักงานในงวด/งวดปลายทาง → ตรวจประวัติการจ้าง; รายการปัจจุบันส่งไม่ได้เมื่อรอบล็อก → ใช้ส่วนหลังล็อก; ห้ามลบหนี้ที่เกิดขึ้นจริงหรือแก้ประวัติค่าตอบแทนเก่า **ต่อไป:** [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน)

## UC14 เปิดงวดเงินเดือน

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของเปิดงวดและดูรายชื่อจากประวัติการจ้าง **ต้องมี:** [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน), [UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา), [UC06](#uc06-กำหนดนโยบายเงินเดือนและการลา)

1. เปิด **เงินเดือน** เลือก **ร้าน** กด **เปิดสมุดงาน**
2. ใน **เปิดรอบเงินเดือน** กรอก **เดือน** เช่น `2026-10` แล้วกด **เปิดรอบ**
3. เลือกงวดในรายการ **รอบเงินเดือน** ตรวจ **พนักงานที่มีประวัติการสังกัดในงวดนี้** และ **ความพร้อมของงวด**; reload เปิดสมุดงานใหม่แล้วเลือกงวดเดิมเพื่อยืนยัน

**ติดขัด:** งวดซ้ำใช้รายการเดิม; รายชื่อขาด → ตรวจช่วงการจ้างใน [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน); config ขาด → [UC06](#uc06-กำหนดนโยบายเงินเดือนและการลา) **ต่อไป:** [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน)

## UC15 คำนวณและตรวจสอบเงินเดือน

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของดูรายได้ รายการหัก และยอดสุทธิ **ต้องมี:** งวดเปิดจาก [UC14](#uc14-เปิดงวดเงินเดือน), ลงเวลาครบจาก [UC07](#uc07-บันทึกและแก้ไขข้อมูลลงเวลา), การตัดสินคำขอ [UC09](#uc09-พิจารณาคำขอลา)/[UC11](#uc11-พิจารณาคำขอทำงานล่วงเวลา)/[UC12](#uc12-จัดการคำขอเงินทดรองและเงินกู้)/[UC13](#uc13-บันทึกหนี้และรายการปรับปรุงเงินเดือน)

1. เปิด **เงินเดือน** เลือก **ร้าน** → **เปิดสมุดงาน** → เลือกงวด แล้วกด **คำนวณตัวอย่าง**
2. ตรวจ **ความพร้อมของงวด**, รายการ **ยังล็อกรอบไม่ได้**, แถวพนักงาน รายได้ รายการหัก และยอดสุทธิ เปิดหลักฐานรายคนตามหน้าจอเพื่อเทียบกับเวลา/คำขอ/หนี้
3. แก้ข้อมูลต้นทางตามลิงก์ **ไปตรวจข้อมูลที่เกี่ยวข้อง** หรือ **ตรวจตารางสาขา** แล้วกด **คำนวณตัวอย่าง** อีกครั้งจนค่าถูกต้อง; reload แล้วคำนวณอีกครั้งได้

**ติดขัด:** ขาดวันลงเวลา, pending approval, assignment/config ไม่ครอบคลุม, หรือยอดสุทธิติดลบต้องแก้ก่อน การคำนวณตัวอย่างเป็น preview ไม่ใช่การจ่ายหรือการล็อก; ลาที่อนุมัติไม่หักแบบขาดงาน ส่วนขาด/สายหักตามกฎรายวัน **ต่อไป:** [UC16](#uc16-ตรวจความพร้อมและล็อกรอบเงินเดือน)

**จำนวนวันทำงานมาตรฐาน:** ระบบนับวันในช่วงการจ้างภายในรอบ หักวันหยุดประจำสัปดาห์ วันหยุดร้าน และวันปิดสาขาที่พนักงานสังกัดในแต่ละวัน โดยวันที่หยุดซ้อนกันนับครั้งเดียว หากย้ายสาขาระหว่างเดือนจะรวมจำนวนวันเป็นตัวหารเดียวสำหรับรอบ ใช้ตัวหารนี้กับค่าแรงรายวันและ OT ตรวจตารางสาขาและวันหยุดก่อนคำนวณ จำนวนวันและรายละเอียดที่ใช้จะถูกเก็บไว้เมื่อคำนวณและล็อกรอบ

## UC16 ตรวจความพร้อมและล็อกรอบเงินเดือน

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของตรึงผลเงินเดือนที่ถูกต้อง **ต้องมี:** [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน) ผ่านการตรวจครบ: วันทำงานครบ ไม่มีคำขอรอตัดสิน ยอดสุทธิไม่ติดลบ และค่าที่ใช้มี snapshot

1. เปิด **เงินเดือน** เลือก **ร้าน** → **เปิดสมุดงาน** → เลือกงวด ตรวจ **ความพร้อมของงวด** และ preview ล่าสุด
2. เมื่อไม่มี blocker กด **ล็อกรอบ** แล้วตอบกล่องยืนยัน **ล็อกรอบนี้หรือไม่? ผลคำนวณและรายการหักจะถูกตรึงเป็นประวัติ**
3. เห็น **ล็อกรอบเงินเดือนแล้ว**; reload เปิดสมุดงาน เลือกงวดเดิม ตรวจสถานะล็อก ยอดเดิม และปุ่มแก้ที่ไม่พร้อม

**ติดขัด:** หากยังเห็น **ยังล็อกรอบไม่ได้** ให้ตามสาเหตุใน [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน); หลังล็อกห้ามแก้ค่าลงเวลา/ผลเดิม ให้ใช้รายการปรับปรุงที่มีประวัติใน [UC13](#uc13-บันทึกหนี้และรายการปรับปรุงเงินเดือน) **ต่อไป:** [UC17](#uc17-ออกและส่งสลิปเงินเดือน), [UC18](#uc18-เตรียมและบันทึกการจ่ายเงินเดือน-พร้อมรายงานและไฟล์จ่าย)

## UC17 ออกและส่งสลิปเงินเดือน

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของออก ดาวน์โหลด และส่ง; พนักงาน รวมถึงหัวหน้า/ผู้จัดการที่บัญชีเชื่อมทะเบียน ดูและดาวน์โหลดเฉพาะสลิปของตน **ต้องมี:** งวดล็อกจาก [UC16](#uc16-ตรวจความพร้อมและล็อกรอบเงินเดือน); บัญชีผู้รับเชื่อมพนักงานจาก [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้)

**ออกและดาวน์โหลด — HR/เจ้าของ**

1. เปิด **สลิปเงินเดือน** ใน **เลือกรายการเงินเดือนที่ล็อกแล้ว** เลือก **ร้าน**, **งวดเงินเดือน**, **พนักงาน** แล้วกด **ออกหรือเปิดสลิป**
2. ตรวจหัวข้อ **สลิป #...** และยอด กด **ดาวน์โหลด PDF**; การกดออกซ้ำจะเปิดสลิปของ payroll record เดิม

**ส่งและตรวจประวัติ — HR/เจ้าของ**

1. ใน **ส่งสลิปทางอีเมล** กรอก **อีเมลผู้รับ** ที่ได้รับอนุญาต กด **ส่งสลิป**
2. ตรวจ **ประวัติการส่ง** ของแต่ละครั้ง แล้ว reload เปิดสลิปเดิมเพื่อตรวจผล สถานะ SMTP รับข้อความหมายถึงผู้ให้บริการรับไว้ ยังต้องตรวจ inbox/ผลส่งจริง; การทดสอบด้วย local SMTP ไม่ยืนยันว่าได้ตั้งค่า SMTP ภายนอก

**ดาวน์โหลดของตน — พนักงาน/หัวหน้า/ผู้จัดการที่เชื่อมทะเบียน**

1. เปิด **สลิปเงินเดือน** → **สลิปเงินเดือนของฉัน** เลือกรายการตนแล้วกด **ดาวน์โหลด PDF**
2. Reload ตรวจว่าสลิปยังอยู่ ไม่มีปุ่มออก/ส่งสลิปของผู้อื่น

**ติดขัด:** ไม่มีสลิป → ให้ HR ตรวจงวดล็อกและออกสลิป; ไม่มีสลิปของตน → ตรวจบัญชีเชื่อมพนักงาน; ส่งไม่สำเร็จ → ให้ผู้ดูแลตรวจ SMTP และประวัติแต่ละครั้ง **ต่อไป:** [UC18](#uc18-เตรียมและบันทึกการจ่ายเงินเดือน-พร้อมรายงานและไฟล์จ่าย)

## UC18 เตรียมและบันทึกการจ่ายเงินเดือน พร้อมรายงานและไฟล์จ่าย

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของเตรียมเงินเดือนตามสาขา บันทึกผลจริง และส่งออกรายงาน **ต้องมี:** งวดล็อกจาก [UC16](#uc16-ตรวจความพร้อมและล็อกรอบเงินเดือน), ปลายทางรับเงินและสมาชิกประกันสังคมที่มีผลจาก [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน)

**เตรียมและจัดกลุ่ม**

1. เปิด **เงินเดือน** เลือก **ร้าน** → **เปิดสมุดงาน** → เลือกงวดที่ล็อก เปิด **ตัวเลือกเพิ่มเติม: เตรียมและบันทึกการจ่ายเงินเดือน** เลือก **สาขาสำหรับเตรียมจ่าย** ตรวจยอดเต็มใน **สรุปการจ่ายเงิน**
2. ดูตาราง **สรุปยอดเงินเดือนตามสาขา** ซึ่งแสดงจำนวนคนและยอดเงินเดือนสุทธิสำหรับ **เงินสด**, **เงินโอน** และ **ประกันสังคม** ของแต่ละสาขา ยอดประกันสังคมในตารางคือยอดเงินเดือนที่โอนให้พนักงานกลุ่มนี้ ไม่ใช่ยอดเงินสมทบ ตรวจกลุ่ม **จ่ายเงินสด**, **จ่ายเงินโอน PromptPay** และ **จ่ายแบบประกันสังคม** ตามประเภทที่พนักงานเลือก ยอดสุทธิศูนย์แสดง **ยอดสุทธิเป็นศูนย์ · ไม่มีภาระจ่าย**
3. หากรายการแจ้ง **แก้ปลายทางรับเงิน** ให้ไปหน้าพนักงาน กำหนด **วิธีรับเงินเดือน**, **หมายเลขรับเงินพร้อมเพย์** หรือบัญชีธนาคารหลักตามกลุ่ม แล้วกลับมาตรวจ; กด **เตรียมจ่ายสาขาที่เลือก** เมื่อพร้อม เห็น **เตรียมแล้ว · ยังไม่จ่าย** ปลายทางและยอดเต็มถูกตรึง ณ ตอนเตรียม การแก้ข้อมูลพนักงานภายหลังไม่เปลี่ยนรายการเตรียมแล้ว

**QR และการจ่ายเงินจริง**

1. สำหรับรายการ PromptPay กด **แสดง QR [รหัสพนักงาน]** ใน **QR รับเงินเดือน** ตรวจเบอร์ผู้รับและยอดเต็มกับหลักฐานก่อนใช้แอปธนาคาร; เบอร์รับเงินนี้ไม่ใช่เบอร์ติดต่อ
2. ดำเนินการโอนในแอปธนาคาร/ช่องทางภายนอกหรือจ่ายเงินสดตามรายการที่เตรียม การสร้างหรือสแกน QR ยังไม่ใช่หลักฐานว่าจ่ายสำเร็จ ระบบนี้ไม่เชื่อมธนาคารอัตโนมัติ

**บันทึกผล ยกเลิก และตรวจประวัติ**

1. เมื่อพิสูจน์ว่าจ่ายจริง กด **ยืนยันจ่ายเงิน** ที่รายการ ตรวจ **ตรวจสอบการจ่ายเงิน**, **ยอดเต็มจำนวน**, ปลายทางที่ตรึง ใส่ **เลขอ้างอิง (ถ้ามี)** ติ๊ก **ตรวจสอบแล้วว่าจ่ายเงินให้พนักงานสำเร็จจริง** แล้วกด **บันทึกว่าจ่ายแล้ว**
2. หากยังไม่จ่ายและต้องยกเลิกการเตรียม กด **ยกเลิกการเตรียมจ่าย** ใส่ **เหตุผลการยกเลิก** กด **บันทึกการยกเลิก**; การยกเลิกในระบบไม่ย้อนเงินโอนที่ธนาคารและไม่ทำให้ QR ที่ดาวน์โหลดแล้วใช้ไม่ได้
3. Reload เปิดงวดเดิมและสาขาเดิม ตรวจ **จ่ายแล้ว**, ประวัติยกเลิก/เลขอ้างอิง และ **จ่ายแล้ว/ค้างจ่าย** ทั้งสาขา; การบันทึกซ้ำแบบผลเดิมไม่เพิ่มการจ่ายซ้ำ แต่การพยายามเปลี่ยนผลปลายทางที่ขัดกันจะถูกปฏิเสธ ให้ตรวจประวัติและปรึกษา HR/เจ้าของ

**รายงานและไฟล์**

1. เปิด **รายงาน** เลือก **ร้าน**, **งวดเงินเดือน** และตัวกรอง **สาขา/แผนก** กด **ดูรายงานสรุป**; กด **ส่งออกสรุปตามตัวกรอง (CSV)** สำหรับยอดรวม หรือ **ส่งออกรายชื่อและยอดเงินเดือน (CSV)** สำหรับข้อมูลรายพนักงาน
2. เมื่อรอบล็อกแล้ว กด **ไฟล์โอนเงินธนาคาร (CSV)** เพื่อส่งออกทั้งรอบโดยใช้บัญชีหลักปัจจุบัน ยอดอาจรวมรายการที่จ่ายแล้ว จึงต้องตรวจสถานะก่อนจ่ายซ้ำ; **รายงานประกันสังคม (CSV)** ส่งออกทั้งรอบ การดาวน์โหลดไม่บันทึกสถานะจ่าย หากบัญชีไม่ครบให้เพิ่มบัญชีหลักก่อน ส่วน **ตัวเลือกเพิ่มเติม: รายงาน PDF และไฟล์ที่เตรียมจ่ายแล้ว** มี PDF ไฟล์ที่ใช้ปลายทางซึ่งตรึงไว้ และรายงานประกันสังคมตามตัวกรอง
3. ฐานประกันสังคมในไฟล์มาจาก **ผลรวมค่าจ้างฐานรายวันที่เกิดจริงในงวด** ไม่รวมสวัสดิการ OT หรือ adjustment; ยอดมาจากงวดที่ล็อก แต่บัญชีในไฟล์โอนเงินทั้งรอบเป็นบัญชีหลักปัจจุบัน ไฟล์ไม่ใช่หลักฐานการโอนหรือการยื่นหน่วยงาน

**ติดขัด:** ปุ่มเตรียมจ่ายไม่พร้อม → ตรวจปลายทางของทุกรายการในสาขา; QR ไม่แสดงสำหรับกลุ่มธนาคาร/เงินสด; ยอดค้างจ่ายไม่ลดจนบันทึกผลจ่ายจริง **ต่อไป:** [UC19](#uc19-ดูภาพรวมและรายงานตามสิทธิ์), [UC20](#uc20-ตรวจสอบประวัติการดำเนินงาน)

## UC19 ดูภาพรวมและรายงานตามสิทธิ์

**เป้าหมาย/ผู้ใช้:** ทุกบทบาทเปิดพื้นที่งานและข้อมูลที่ grant อนุญาต; HR/เจ้าของเท่านั้นดู/ส่งออกรายงานการเงิน **ต้องมี:** [UC01](#uc01-เข้าสู่ระบบและจัดการรหัสผ่าน), grant/scope จาก [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้), งวดสำหรับรายงานจาก [UC14](#uc14-เปิดงวดเงินเดือน)

1. เปิด **ภาพรวม** อ่าน **เริ่มงานประจำวัน** แล้วกดลิงก์งานที่ได้รับสิทธิ์ เช่น **การลา** หรือ **ลงเวลา**
2. HR/เจ้าของเปิด **รายงาน** เลือก **ร้าน**, **งวดเงินเดือน**, ตัวกรอง **สาขา**, **แผนก** กด **ดูรายงานสรุป**; หากต้องการข้อมูลตามตัวกรอง กด **ส่งออกสรุปตามตัวกรอง (CSV)** ตรวจยอดและ reload แล้วเลือกตัวกรองเดิม

**ติดขัด:** ไม่เห็นรายงานการเงินสำหรับพนักงาน/หัวหน้า/ผู้จัดการเป็นไปตามสิทธิ์; workspace ของแต่ละคนไม่ใช่ dashboard การเงินรวมทั้งร้าน หากข้อมูลใน scope ขาด ให้ HR ตรวจ grant และประวัติสังกัด **ต่อไป:** [UC20](#uc20-ตรวจสอบประวัติการดำเนินงาน) สำหรับ HR/เจ้าของ

## UC20 ตรวจสอบประวัติการดำเนินงาน

**เป้าหมาย/ผู้ใช้:** HR/เจ้าของอ่าน audit ทุกสาขา **ต้องมี:** [UC01](#uc01-เข้าสู่ระบบและจัดการรหัสผ่าน), การดำเนินงานที่สร้างประวัติจาก UC ก่อนหน้า

1. เปิด **ประวัติการเปลี่ยนแปลง** กรองด้วย **การดำเนินการ**, **ตารางข้อมูล**, **รหัสรายการ**, **รหัสบัญชีผู้ดำเนินการ**, **ตั้งแต่เวลา**, **ถึงเวลา** หรือ **Request ID** ตามข้อมูลที่ทราบ เช่นตาราง `shops` กับรหัสร้าน
2. กด **ค้นหาประวัติ** ตรวจผู้ดำเนินการ เวลา target เหตุผล และข้อมูลเดิม/ใหม่ที่แสดง; reload แล้วใช้ตัวกรองเดิมเพื่อตรวจว่าแถวยังอยู่

**ติดขัด:** ไม่พบรายการ → ลดตัวกรองหรือปรับช่วงเวลา; ผู้ไม่มี HR/OWNER จะเข้าไม่ได้ ให้ผู้มีสิทธิ์ช่วยตรวจ Audit เป็นข้อมูลอ่านอย่างเดียว ไม่มีปุ่มแก้/ลบประวัติ และไม่ควรแสดงรหัสผ่าน token หรือเลขบัญชีเต็ม **ต่อไป:** กลับ [UC19](#uc19-ดูภาพรวมและรายงานตามสิทธิ์) เพื่อตรวจงานที่เกี่ยวข้อง

## เช็กลิสต์สาธิตครั้งแรก

1. เจ้าของ/HR ใช้บัญชีที่ผู้ติดตั้งมอบให้ เปิด [UC02](#uc02-จัดการโครงสร้างองค์กร) สร้างร้าน–สาขา–แผนก–ตำแหน่ง แล้วสร้างพนักงานและช่วงการจ้าง [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน)
2. เชื่อมบัญชีพนักงานกับทะเบียนที่เพิ่งสร้างและให้ self grant ใน [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้); ตั้งตาราง [UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา) และ config/สิทธิ์ลา [UC06](#uc06-กำหนดนโยบายเงินเดือนและการลา)
3. พนักงานลงเวลาของตน [UC07](#uc07-บันทึกและแก้ไขข้อมูลลงเวลา) ส่งลา [UC08](#uc08-ยื่นคำขอลา) และ OT [UC10](#uc10-ยื่นและแก้ไขคำขอทำงานล่วงเวลา); ผู้ดูแลที่มีสิทธิ์พิจารณา [UC09](#uc09-พิจารณาคำขอลา)/[UC11](#uc11-พิจารณาคำขอทำงานล่วงเวลา)
4. HR เปิดงวด [UC14](#uc14-เปิดงวดเงินเดือน) ทำ preview [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน) ตรวจครบก่อนล็อก [UC16](#uc16-ตรวจความพร้อมและล็อกรอบเงินเดือน) โดยใช้ข้อมูลสมมติในสภาพแวดล้อมสาธิตเท่านั้น
5. ออกสลิป [UC17](#uc17-ออกและส่งสลิปเงินเดือน), เตรียมและตรวจสถานะจ่าย [UC18](#uc18-เตรียมและบันทึกการจ่ายเงินเดือน-พร้อมรายงานและไฟล์จ่าย), ตรวจรายงาน [UC19](#uc19-ดูภาพรวมและรายงานตามสิทธิ์) และ audit [UC20](#uc20-ตรวจสอบประวัติการดำเนินงาน)

## คำศัพท์สั้น ๆ

| คำ | ความหมาย |
|---|---|
| grant / scope | สิทธิ์การทำงานและขอบเขตพนักงาน/แผนก/สาขาที่บัญชีมองเห็น |
| effective date | วันที่ข้อมูลช่วงใหม่เริ่มมีผล; ประวัติเดิมยังอยู่ |
| pending / รอพิจารณา | ส่งคำขอแล้ว แต่ยังไม่อนุมัติและยังไม่ใช้สิทธิ์/เงิน |
| preview / คำนวณตัวอย่าง | ยอดที่คำนวณให้ตรวจ; ยังไม่ตรึงผล |
| locked / ล็อก | งวดและค่าที่ใช้ถูกตรึงเป็นหลักฐาน; แก้ผ่าน adjustment ในงวดหลัง |
| prepared / เตรียมแล้ว | ตรึงปลายทางและยอดจ่าย; ยังไม่ยืนยันว่าจ่ายจริง |
| paid / จ่ายแล้ว | ผู้มีสิทธิ์ตรวจหลักฐานภายนอกและบันทึกยืนยันในระบบ |

## เมื่อทำรายการไม่สำเร็จ

| อาการ | ตรวจและทำต่อ |
|---|---|
| ไม่เห็นเมนู/พนักงาน | ให้ HR/เจ้าของตรวจบทบาท, grant และสาขา/แผนกใน [UC03](#uc03-จัดการบัญชีและสิทธิ์ผู้ใช้) |
| เลือกสาขา/พนักงานไม่ได้ | เลือกร้านและ parent ก่อน; ตรวจข้อมูล [UC02](#uc02-จัดการโครงสร้างองค์กร)/[UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน), แล้วกดปุ่มโหลดของหน้านั้น |
| ลงเวลาไม่ได้ | ตรวจ assignment ในวันนั้นและตารางที่มีผล [UC04](#uc04-จัดการข้อมูลและประวัติพนักงาน)/[UC05](#uc05-กำหนดตารางทำงานและวันหยุดสาขา); ตรวจว่างวดยังไม่ล็อก |
| ลาไม่ผ่าน | ตรวจ quota รายปีทุกปี ประเภท และช่วงวันที่ไม่ซ้อน [UC06](#uc06-กำหนดนโยบายเงินเดือนและการลา)/[UC08](#uc08-ยื่นคำขอลา) |
| เงินทดรองไม่ผ่าน | ตรวจวันขอ จำนวนวันทำงาน เพดานครึ่งเงินเดือนฐาน และยอดสุทธิ [UC12](#uc12-จัดการคำขอเงินทดรองและเงินกู้) |
| ล็อกงวดไม่ได้ | เปิด **ยังล็อกรอบไม่ได้** แก้วันทำงาน คำขอ pending ค่าคำนวณ หรือยอดติดลบ แล้ว preview ใหม่ [UC15](#uc15-คำนวณและตรวจสอบเงินเดือน) |
| เตรียมจ่าย/ไฟล์ธนาคารไม่ได้ | ตรวจบัญชีหลัก/เบอร์ผู้รับและกลุ่มจ่ายที่ตรึงไว้ [UC18](#uc18-เตรียมและบันทึกการจ่ายเงินเดือน-พร้อมรายงานและไฟล์จ่าย) |

เมื่อแจ้งผู้ดูแล ให้ส่งชื่อหน้า เวลา ข้อความ error/Request ID และรหัสรายการที่ไม่ลับ **อย่าส่งรหัสผ่าน token เลขบัตรหรือเลขบัญชีเต็ม** ผ่านแชตหรือภาพหน้าจอ
